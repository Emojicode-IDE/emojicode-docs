# Emojicode IDE — docs & issues

[Emojicode IDE](https://emojicode-ide.com/) のドキュメント（非公式リファレンス）の原稿と、画面の文言の翻訳です。IDE やドキュメントへの不具合の報告・要望も、ここの [Issues](https://github.com/Emojicode-IDE/emojicode-docs/issues/new/choose) で受け付けています。

The manuscripts of the [Emojicode IDE](https://emojicode-ide.com/) documentation (an unofficial reference) and the UI translations. Bug reports and requests for the IDE or the docs are also welcome in [Issues](https://github.com/Emojicode-IDE/emojicode-docs/issues/new/choose).

> このプロジェクトは [Emojicode](https://www.emojicode.org/) の開発元とは関係のない、非公式のものです。言語仕様は公式の [Language Reference](https://www.emojicode.org/docs/reference) にまとまっていて、このドキュメントはそれを補う、動かしながら学ぶための資料です。
> This project is unofficial and not affiliated with the developers of [Emojicode](https://www.emojicode.org/). The language is fully documented in the official [Language Reference](https://www.emojicode.org/docs/reference); these docs are a companion for learning by running code.

## 中身 / Contents

| パス / Path | 内容 / What |
|---|---|
| `docs/` | 日本語の原稿（原文）と目次 `_toc.json` / Japanese manuscripts (the originals) and the table of contents |
| `docs/<lang>/` | ほかの言語の原稿（日本語と同じ slug）/ Translations, with the same slugs as the Japanese pages |
| `ui/<lang>.json` | 画面の文言の翻訳（キーは日本語の原文）/ UI translations (keys are the original Japanese strings) |

`docs/basics/strings.md` は https://emojicode-ide.com/docs/basics/strings/ に、`docs/en/basics/strings.md` は https://emojicode-ide.com/en/docs/basics/strings/ になります。
`docs/basics/strings.md` becomes https://emojicode-ide.com/docs/basics/strings/, and `docs/en/basics/strings.md` becomes https://emojicode-ide.com/en/docs/basics/strings/.
