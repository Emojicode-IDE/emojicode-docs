# 【重要】コンパイラの内部仕様を変更しました

この IDE のコンパイラが、公式コンパイラ（[`master`](https://github.com/emojicode/emojicode/tree/master) の [`4dec45b`](https://github.com/emojicode/emojicode/commit/4dec45b497e4f4dce7f5f5ae11a00d8e8e9af67c)）と同じ結果を返すようになりました。

これまでは、公式コンパイラのいくつかの不具合を直すパッチを当てた、独自のコンパイラを使っていました。そのため、同じコードでも公式コンパイラと結果が違うことがありました。今回このパッチを外したので、前は正しい値が出ていたコードでも、公式と同じ値が出たり、エラーで止まったりすることがあります。

### 結果が変わったときは

公式コンパイラで落ちる、終わらない、コンパイルできない書き方は、`[EJ001]` のようなエラー ID のついたエラーで止まります。出力に出たエラー ID をクリックすると、その不具合の説明と避け方が開きます。

エラーにならずに値だけが変わったときは、[Emojicode言語のバグ](../docs/about/known-issues.md)のページで、使っているメソッドを探してください。公式コンパイラでどうなるかと、避ける書き方を載せています。
