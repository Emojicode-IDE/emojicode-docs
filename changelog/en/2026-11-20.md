# [Important] Changed the compiler's internal behavior

The compiler in this IDE now gives the same results as the official compiler ([`master`](https://github.com/emojicode/emojicode/tree/master) at [`4dec45b`](https://github.com/emojicode/emojicode/commit/4dec45b497e4f4dce7f5f5ae11a00d8e8e9af67c)).

Until now, this IDE used its own compiler, with patches that fixed several bugs in the official compiler, so the same code could give different results here and with the official compiler. These patches have now been removed, so code that used to print the correct value may now print what the official compiler prints, or stop with an error.

### If your results changed

Code that crashes, never finishes, or fails to compile with the official compiler now stops with an error that carries an error ID such as `[EJ001]`. Click the error ID in the output to open an explanation of the bug and how to avoid it.

If there is no error but a value changed, look up the method you use on the [Emojicode Language Bugs](../docs/about/known-issues.md) page. It shows what the official compiler does and how to avoid the bug.
