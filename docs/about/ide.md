# この IDE の使い方

Emojicode IDE は、ブラウザの中だけで Emojicode をコンパイルして実行します。書いたコードはサーバーに送られません。

## 画面

| 場所 | できること |
|---|---|
| エディタ | コードを書く。`🍇` で改行すると字下げされ、行頭に `🍉` を打つと戻る |
| ▶ 実行 | コンパイルして実行する。実行中は ■ 停止 になる |
| ⌨️ | 絵文字キーボード。よく使う絵文字が種類ごとに並んでいる |
| 出力 | プログラムが表示したもの。コンパイルエラーもここに出る |
| 標準入力 | プログラムが `👂🏼` で読む内容を、実行の前に書いておく |
| 📄 | テンプレート。サンプルや、自分で保存したコードから書き始める |

表示する言語は、ヘッダーの 🌐 から変えられます（画面が狭いときは ⚙︎ 設定の「言語」）。

## はじめて開いたとき

最初の 1 回だけ、コンパイラ一式（約 35 MB）をダウンロードします。2 回目からはダウンロードせずにすぐ起動し、オフラインでも使えます。

## エラーが出たら

コンパイルエラーは、出力に行と列つきで出て、コードの該当する場所に赤い波線が引かれます。出力のエラーを押すと、その場所に移動します。下の例で **▶ 実行** を押すと、このページの中でも同じように見られます。

```emojicode error
🏁 🍇
  😀 🔤とじわすれ❗️
🍉
```

```text
Unexpected end of file.
```

この例では、文字列を閉じる `🔤` がないので、ファイルの最後まで文字列が続いてしまっています。

## 無限ループ

実行が 10 秒たっても終わらないときは、自動で止めます。出力が 20 万文字を超えたときも、そこで打ち切ります。

---

> **この IDE の制限**（ブラウザの中で動かしているため）
>
> - スレッドはありません。`🧵` はクロージャをその場で実行するだけで、`Mutex` は何もしません。
> - `💻`（シェルのコマンドを実行する）は何もしません。
> - 標準入力は、実行前に書いておく方式です。実行中に入力を待つことはできません。
> - `📦 sockets` は使えません。
> - メモリは最大 4 GB です（スマホではもっと少ないことがあります）。
