# プライバシーとアクセス解析

この IDE とドキュメントでは、サービスの向上とより使いやすくするために、アクセス解析を使っています。ログインはなく、名前やメールアドレスなど、個人を特定する情報は集めません。

## アクセス解析

[Google タグ マネージャー](https://marketingplatform.google.com/about/tag-manager/) と [Google アナリティクス](https://marketingplatform.google.com/about/analytics/) を使っています。Google アナリティクスは Cookie を使って、ページの閲覧状況などを Google に送ります。どんな情報が集められ、どう扱われるかは、[Google のサービスを使用するサイトやアプリから収集した情報の Google による使用](https://policies.google.com/technologies/partner-sites) をご覧ください。

## 送らないもの

エディタに書いたコード、標準入力、実行の結果、保存したテンプレートは、ブラウザの中にだけ保存され、サーバーにもアクセス解析にも送りません。コンパイルと実行も、すべてブラウザの中で行います。

## 計測を止めたいとき

[Google アナリティクス オプトアウト アドオン](https://tools.google.com/dlpage/gaoptout) を入れると、Google アナリティクスに送られなくなります。ブラウザの設定で Cookie を受け付けないようにすることもできます。どちらの場合も IDE はそのまま使えます。
