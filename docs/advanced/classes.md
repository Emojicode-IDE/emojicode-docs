# クラスの応用

## 子クラスで必ず作る初期化子（🔑）

初期化子に `🔑` をつけると、子クラスもその初期化子を必ず用意しなければならなくなります。子クラスの側でも `🔑` をつけて書きます。

ただし、子クラスで `🔑` の初期化子を書くと、公式コンパイラは内部のチェックで止まります（[EJ032](../about/known-issues.md#EJ032)）。この IDE でも、`[EJ032]` のエラーになります。

```emojicode error
🐇 🐾 🍇
  🖍🆕 name 🔡
  🔑 🆕 🍼 name 🔡 🍇🍉
  ❗️ 🏷 ➡️ 🔡 🍇
    ↩️ name
  🍉
🍉

🐇 🐕 🐾 🍇
  🔑 🆕 name 🔡 🍇
    ⤴️🆕 name❗️
  🍉
🍉

🏁 🍇
  😀 🏷 🆕🐕 🔤ポチ🔤❗️❗️❗️
🍉
```

```text
[EJ032]
```

子クラスで初期化子を書かなければ、親の `🔑` の初期化子で作れます。

```emojicode
🐇 🐾 🍇
  🖍🆕 name 🔡
  🔑 🆕 🍼 name 🔡 🍇🍉
  ❗️ 🏷 ➡️ 🔡 🍇
    ↩️ name
  🍉
🍉

🐇 🐕 🐾 🍇
🍉

🏁 🍇
  😀 🏷 🆕🐕 🔤ポチ🔤❗️❗️❗️
🍉
```

```output
ポチ
```

```keywords

必須の初期化子
コンストラクタの継承
```

## 継承できないメソッド（🔏）

メソッドに `🔏` をつけると、子クラスで上書きできなくなります。

```emojicode error
🐇 🐾 🍇
  🆕 🍇🍉
  🔏❗️ 🗣 🍇
    😀 🔤…🔤❗️

🍉

  ✒️ ❗️ 🗣 🍇
    😀 🔤ワン🔤❗️
  🍉
🍉

🏁 🍇
  🗣 🆕🐕❗️❗️
🍉
```

## 見える範囲（🔓・🔒・🔐）

メソッドの前に書いて、どこから呼べるかを決めます。

| 書き方 | 呼べるところ |
|---|---|
| `🔓`（または何も書かない） | どこからでも |
| `🔐` | そのクラスと、子クラスの中から |
| `🔒` | そのクラスの中からだけ |

```emojicode
🐇 🐾 🍇
  🆕 🍇🍉
  🔐❗️ 💓 ➡️ 🔡 🍇
    ↩️ 🔤ドキドキ🔤
  🍉
🍉

🐇 🐕 🐾 🍇
  ❗️ 🎧 🍇
    😀 💓👇❗️❗️
  🍉
🍉

🏁 🍇
  🎧 🆕🐕❗️❗️
🍉
```

```output
ドキドキ
```

```keywords
public
protected
private
アクセス修飾子
可視性
```

## 片付けるときの処理（♻️）

`♻️ 🍇 … 🍉` は、インスタンスが使われなくなって片付けられるときに実行されます（デストラクタ）。

```emojicode
🐇 🎈 🍇
  🖍🆕 color 🔡
  🆕 🍼 color 🔡 🍇
    😀 🔤🧲color🧲 の風船をふくらませた🔤❗️
  🍉
  ♻️ 🍇
    😀 🔤🧲color🧲 の風船がしぼんだ🔤❗️
  🍉
🍉

🏁 🍇
  🆕🎈 🔤赤🔤❗️ ➡️ red
  😀 🔤---🔤❗️
🍉
```

```output
赤 の風船をふくらませた
---
赤 の風船がしぼんだ
```

Emojicode は参照カウントでメモリを管理していて、最後の参照がなくなった時点で片付けます（[メモリと参照](memory.md)）。

```keywords
destructor
デストラクタ
~
deinit
finalize
後片付け
```

## メソッドだけのジェネリクス

メソッド名の後ろに `🐚名前 制約🍆` を書くと、そのメソッドだけで使う型を受け取れます。

```emojicode
🐇 🧰 🍇
  🐇❗️ 👯 🐚T ⚪️🍆 value T count 🔢 ➡️ 🍨🐚T🍆 🍇
    🆕🍨🐚T🍆❗️ ➡️ 🖍🆕 list
    🔂 i 🆕⏩ 0 count❗️ 🍇
      🐻 list value❗️
    🍉
    ↩️ list
  🍉
🍉

🏁 🍇
  👯🐇🧰 🔤やあ🔤 3❗️ ➡️ greetings
  😀 🆕🔡 greetings 🔤 🔤❗️❗️
  👯🐇🧰 7 2❗️ ➡️ sevens
  😀 🔡 📏 sevens❓❗️❗️
🍉
```

```output
やあ やあ やあ
2
```

型を書かなくても、引数から決まります。

```keywords
関数テンプレート
template function
ジェネリックメソッド
型推論
```
