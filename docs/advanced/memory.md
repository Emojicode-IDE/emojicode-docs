# メモリと参照

## 参照カウント

クラスのインスタンスは、いくつの変数などから使われているか（参照の数）を数えています。数が 0 になった時点で片付けられ、`♻️` があれば実行されます（[クラスの応用](classes.md)）。ガベージコレクタはありません。

```emojicode
🐇 🎈 🍇
  🆕 🍇🍉
  ♻️ 🍇
    😀 🔤片付けた🔤❗️
  🍉
🍉

🐇 🧒 🍇
  🖍🆕 balloon 🎈
  🆕 🍼 balloon 🎈 🍇🍉
🍉

🏁 🍇
  🆕🎈❗️ ➡️ balloon
  🆕🧒 balloon❗️ ➡️ child
  😀 🔤まだ使っている🔤❗️
🍉
```

```output
まだ使っている
片付けた
```

```keywords
reference counting
参照カウント
ARC
shared_ptr
std::shared_ptr
メモリ管理
ガベージコレクション
GC
```

## 参照が自分だけか（🏮）

`🏮 インスタンス変数` は、そのインスタンスを参照しているのが自分だけかを調べます。

```emojicode
🐇 🐟 🍇
  🆕 🍇🍉
🍉

🐇 🦍 🍇
  🖍🆕 fish 🐟
  🆕 🍇
    🆕🐟❗️ ➡️ 🖍fish
  🍉
  ❗️ 🔎 🍇
    ↪️ 🏮fish 🍇
      😀 🔤参照は自分だけ🔤❗️
    🍉
    🙅 🍇
      😀 🔤ほかにも参照がある🔤❗️
    🍉
  🍉
  ❗️ 🐠 ➡️ 🐟 🍇
    ↩️ fish
  🍉
🍉

🏁 🍇
  🆕🦍❗️ ➡️ gorilla
  🔎 gorilla❗️
  🐠 gorilla❗️ ➡️ other
  🔎 gorilla❗️
🍉
```

```output
参照は自分だけ
ほかにも参照がある
```

書き換える前に「ほかの人が使っていなければそのまま、使っていればコピーしてから」を決めるとき（コピーオンライト）に使います。

```keywords
use_count
unique
コピーオンライト
copy on write
参照カウント
🏮
```

## 弱い参照（📶）

お互いを参照し合うと、どちらの数も 0 にならず、片付けられなくなります（循環参照）。片方を `📶`（弱い参照）にすると、数に入れずに参照できます。中身は `🐽 弱い参照❗️` で取り出し、もう片付けられていれば値なしです。

```emojicode
🐇 🐟 🍇
  🖍🆕 name 🔡
  🆕 🍼 name 🔡 🍇🍉
  ❗️ 🏷 ➡️ 🔡 🍇
    ↩️ name
  🍉
  ♻️ 🍇
    😀 🔤🧲name🧲 を片付けた🔤❗️
  🍉
🍉

🏁 🍇
  🆕🐟 🔤ニモ🔤❗️ ➡️ fish
  🆕📶🐚🐟🍆 fish❗️ ➡️ weak
  ↪️ 🐽 weak❗️ ➡️ f 🍇
    😀 🔤まだいる: 🧲🏷 f❗️🧲🔤❗️
  🍉
  🆕📶🐚🐟🍆 🆕🐟 🔤ドリー🔤❗️❗️ ➡️ weak2
  ↪️ 🐽 weak2❗️ 🙌 🤷‍♀️ 🍇
    😀 🔤ドリーはもういない🔤❗️
  🍉
🍉
```

```output
まだいる: ニモ
ドリー を片付けた
ドリーはもういない
ニモ を片付けた
```

`🆕🐟 🔤ドリー🔤❗️` は、弱い参照にしか入れていないので、すぐに片付けられます。

```keywords
weak
weak_ptr
std::weak_ptr
弱参照
循環参照
メモリリーク
```

## 値型はコピー、クラスは参照

値型（`🕊`）は代入するとコピーされますが（[値型と列挙型](../types/valuetypes.md)）、クラスは代入しても同じインスタンスを指します。標準ライブラリのリスト（`🍨`）や辞書（`🍯`）も値型です（[リストと辞書](../basics/collections.md)）。

```emojicode
🐇 📦 🍇
  🖍🆕 count 🔢 ⬅️ 0
  🆕 🍇🍉
  ❗️ 🆙 🍇
    count ⬅️➕ 1
  🍉
  ❗️ 🔢 ➡️ 🔢 🍇
    ↩️ count
  🍉
🍉

🏁 🍇
  🆕📦❗️ ➡️ a
  a ➡️ b
  🆙 b❗️
  😀 🔡 🔢 a❗️❗️❗️
🍉
```

```output
1
```

`b` に足したのに、`a` から見ても 1 になっています。`a` と `b` は同じインスタンスを指しているからです。

```keywords
参照
参照渡し
ポインタ
reference
&
コピー
浅いコピー
```

## 値型の中身への参照を返す（✴️）

値型のメソッドの戻り値を `✴️型` にすると、コピーではなく、中身そのものへの参照を返します。返ってきたものを書き換えると、もとの値が変わります。

```emojicode
🕊 📊 🍇
  🖍🆕 value 🔢 ⬅️ 0
  🆕 🍇🍉
  🖍❗️ 🆙 🍇
    value ⬅️➕ 1
  🍉
  ❗️ 👀 ➡️ 🔢 🍇
    ↩️ value
  🍉
🍉

🕊 🗄 🍇
  🖍🆕 counter 📊 ⬅️ 🆕📊❗️
  🆕 🍇🍉
  ❗️ 🔍 ➡️ ✴️📊 🍇
    ↩️ counter
  🍉
  ❗️ 📤 ➡️ 📊 🍇
    ↩️ counter
  🍉
🍉

🏁 🍇
  🆕🗄❗️ ➡️ 🖍🆕 drawer
  🆙 🔍 drawer❗️❗️
  😀 🔡 👀 🔍 drawer❗️❗️❗️❗️
  📤 drawer❗️ ➡️ 🖍🆕 copy
  🆙 copy❗️
  😀 🔡 👀 🔍 drawer❗️❗️❗️❗️
🍉
```

```output
1
1
```

`🔍` は参照を返すので、`🆙` で `drawer` の中身が 1 になります。`📤` はコピーを返すので、`copy` を書き換えても `drawer` は 1 のままです。

```keywords
参照を返す
reference
&
ゲッター
✴
```
