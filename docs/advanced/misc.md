# 細かい記法

ふだんはあまり使わない、上級者向けの記法です。

## 値を返さない（◼️）

戻り値の型の位置に `◼️` を書くと、「値を返さない」ことをはっきり書けます。クロージャの型で使うことが多いです。

```emojicode
🏁 🍇
  🍇 ➡️ ◼️
    😀 🔤何も返さない🔤❗️
  🍉 ➡️ f
  ⁉️ f❗️
🍉
```

```output
何も返さない
```

```keywords
void
戻り値なし
◼
```

## 型の大きさ（⚖️）

`⚖️型` は、その型の値 1 つが何バイトかを返します。

```emojicode
🏁 🍇
  😀 🔡 ⚖️🔢❗️❗️
  😀 🔡 ⚖️💯❗️❗️
  😀 🔡 ⚖️👌❗️❗️
🍉
```

```output
8
8
1
```

```keywords
sizeof
大きさ
バイト数
⚖
```

## 非推奨（⚠️）

メソッドに `⚠️` をつけると、そのメソッドを使ったところで警告が出ます。動きは変わりません。

```emojicode
🐇 🧓 🍇
  ⚠️🐇❗️ 📠 🍇
    😀 🔤古いメソッド🔤❗️
  🍉
🍉

🏁 🍇
  📠🐇🧓❗️
🍉
```

```output
古いメソッド
```

コンパイルすると `⚠️ warning: 📠 is deprecated.` という警告が出ます。

```keywords
deprecated
[[deprecated]]
非推奨
警告
⚠
```

## インライン化（🥯）

メソッドに `🥯` をつけると、呼び出すところに中身を展開するようコンパイラに頼みます。動きは変わりません。

```emojicode
🐇 ➰ 🍇
  🥯🐇❗️ ✌️ n 🔢 ➡️ 🔢 🍇
    ↩️ n ✖️ 2
  🍉
🍉

🏁 🍇
  😀 🔡 ✌️🐇➰ 21❗️❗️❗️
🍉
```

```output
42
```

```keywords
inline
インライン
最適化
```

## 安全でない処理（☣️）

`☣️ 🍇 … 🍉` の中では、メモリを直接扱うような、安全でない処理を書けます。標準ライブラリの中で使われていますが、ふつうのプログラムで使うことはありません。

```emojicode
🏁 🍇
  ☣️ 🍇
    😀 🔤unsafe の中🔤❗️
  🍉
🍉
```

```output
unsafe の中
```

```keywords
unsafe
安全でない
☣
```

## ジェネリクスの型ごとの処理を省く（🎍🛢）

ジェネリックな値型に `🎍🛢` をつけると、型引数ごとの実行時の情報を作らないようにします。標準ライブラリのリストや辞書の中で使われています。

```emojicode
🎍🛢 🕊 📦🐚T ⚪️🍆 🍇
  🖍🆕 v T
  🆕 🍼 v T 🍇🍉
  ❗️ 📤 ➡️ T 🍇
    ↩️ v
  🍉
🍉

🏁 🍇
  😀 📤 🆕📦🐚🔡🍆 🔤ok🔤❗️❗️❗️
🍉
```

```output
ok
```

```keywords
🛢
generic dynamism
```

## 廃止された書き方（🔟）

`🔟` で始まる「記号リテラル」は、古い Emojicode にあった書き方で、今は使えません。書くとコンパイルエラーになります。1 文字を扱いたいときは、文字列（`🔤`）を使います。

```emojicode error
🏁 🍇
  🔟🍎 ➡️ s
🍉
```

```text
🔣 has been removed.
```

```keywords
記号
symbol
char
文字
🔟
🔣
```
