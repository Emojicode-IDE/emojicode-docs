# ビット演算と数値

## ビット演算

| 書き方 | 意味 |
|---|---|
| `a ⭕ b` | ビットごとの AND |
| `a 💢 b` | ビットごとの OR |
| `a ❌ b` | ビットごとの XOR |
| `a 👈 n` | 左に n ビットずらす |
| `a 👉 n` | 右に n ビットずらす |
| `❎ a❗️` | ビットを反転する（NOT） |

```emojicode
🏁 🍇
  12 ➡️ a  💭 2 進数で 1100
  10 ➡️ b  💭 2 進数で 1010
  😀 🔡 a ⭕ b 2❗️❗️
  😀 🔡 a 💢 b 2❗️❗️
  😀 🔡 a ❌ b 2❗️❗️
  😀 🔡 1 👈 4❗️❗️
  😀 🔡 256 👉 2❗️❗️
🍉
```

```output
1000
1110
110
16
64
```

## 符号を反転する（🔋）

`🔋 数❗️` で、符号を反転した値（`-x`）になります。

```emojicode
🏁 🍇
  5 ➡️ n
  😀 🔡 🔋 n❗️❗️❗️
  😀 🔡 🔋 2.5❗️ 1❗️❗️
🍉
```

```output
-5
-2.5
```

## 数学の関数

実数（`💯`）には、数学の関数がメソッドとして用意されています。

| 書き方 | 意味 |
|---|---|
| `⛷ x❗️` | 平方根 |
| `🏂 x y❗️` | x の y 乗 |
| `🏧 x❗️` | 絶対値（整数にもある） |
| `📓 x❗️` `📕 x❗️` `📐 x❗️` | sin・cos・tan |
| `🔢 x❗️` | 整数にする（小数点以下を捨てる） |

```emojicode
🏁 🍇
  😀 🔡 ⛷ 2.0❗️ 4❗️❗️
  😀 🔡 🏂 2.0 10.0❗️ 0❗️❗️
  😀 🔡 🏧 -7❗️❗️❗️
  😀 🔡 🔢 3.9❗️❗️❗️
🍉
```

```output
1.4142
1024
7
3
```
