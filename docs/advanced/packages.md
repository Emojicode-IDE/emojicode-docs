# パッケージとドキュメントコメント

## パッケージを読み込む（📦）

`📦 名前 🏠` で、パッケージを読み込みます。標準ライブラリの `s` は、書かなくても最初から読み込まれています。この IDE では、`s` のほかに `files`、`json`、`testtube` を使えます。

```emojicode
📦 json 🏠

🏁 🍇
  🍺 ⚪️🕊🌸 🔤{"name": "えもじ", "age": 3}🔤❗️ ➡️ value
  ↪️ 🔲 value 🍯🐚⚪️🍆 ➡️ object 🍇
    ↪️ 🐽 object 🔤name🔤❗️ ➡️ name 🍇
      ↪️ 🔲 name 🔡 ➡️ text 🍇
        😀 text❗️
      🍉
    🍉
  🍉
🍉
```

```output
えもじ
```

`🏠` は「読み込んだ型を、自分のファイルと同じ名前空間に入れる」という意味です。`🏠` の代わりに名前空間の絵文字を書くと、その名前空間に入ります。名前空間の中の型は `🔶名前空間型` と書いて使います。

```keywords

include

using

モジュール

JSON
```

## ドキュメントコメント（📗・📘）

ふつうのコメント（`💭`）とは別に、型やパッケージの説明を書くためのコメントがあります（`💭` は [Hello World](../intro/hello.md) を参照）。

| 書き方 | 意味 |
|---|---|
| `📗 … 📗` | 型やメソッドの説明。直後の型・メソッドの説明になる |
| `📘 … 📘` | パッケージ全体の説明 |

```emojicode
📗 あいさつをする型 📗
🐇 👋 🍇
  🆕 🍇🍉
  📗 名前を受け取って、あいさつの文を返す 📗
  ❗️ 💬 name 🔡 ➡️ 🔡 🍇
    ↩️ 🔤こんにちは、🧲name🧲🔤
  🍉
🍉

🏁 🍇
  😀 💬 🆕👋❗️ 🔤えもじ🔤❗️❗️
🍉
```

```output
こんにちは、えもじ
```

```keywords
コメント
ドキュメントコメント
doxygen
javadoc
///
/** */
```

## この IDE では使えないもの

- `📜 🔤ファイル名🔤` … 別のファイルを読み込む。この IDE はファイル 1 つだけをコンパイルするので使えません。
- `🌍` … 型を、パッケージの外に公開する。パッケージを作るときに使います。
- `📻`・`🔗` … C++ などで書いた関数とつなぐ。この IDE では使えません。
