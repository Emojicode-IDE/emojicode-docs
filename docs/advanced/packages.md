# パッケージとドキュメントコメント

## パッケージを読み込む（📦）

`📦 名前 🏠` で、パッケージを読み込みます。標準ライブラリの `s` は、書かなくても最初から読み込まれています。この IDE では、`s` のほかに `files`、`json`、`testtube` を使えます。

```emojicode
📦 json 🏠

🏁 🍇
  🍺 ⚪️🕊🌸 🔤{"name": "えもじ", "age": 3}🔤❗️ ➡️ value
  ↪️ 🔲 value 🍯🐚⚪️🍆 ➡️ object 🍇
    ↪️ 🐽 object 🔤name🔤❗️ ➡️ name 🍇
      ↪️ 🔲 name 🔡 ➡️ text 🍇
        😀 text❗️
      🍉
    🍉
  🍉
🍉
```

```output
えもじ
```

`🏠` は「読み込んだ型を、自分のファイルと同じ名前空間に入れる」という意味です。`🏠` の代わりに名前空間の絵文字を書くと、その名前空間に入ります。名前空間の中の型は `🔶名前空間型` と書いて使います。


## ファイルを読み書きする（📦 files）

この IDE では、ファイルはプログラムを動かしている間だけ、メモリの中にあります。

```emojicode
📦 files 🏠

🏁 🍇
  🍺 📻🐇📄 🔤memo.txt🔤 📇 🔤こんにちは🔤❗️❗️
  🍺 📇🐇📄 🔤memo.txt🔤❗️ ➡️ data
  😀 🍺 🔡 data❗️❗️
🍉
```

```output
こんにちは
```

| 書き方 | 意味 |
|---|---|
| `📻🐇📄 パス データ❗️` | データ（`📇`）をファイルに書く。ファイルがあれば中身を置き換える |
| `📇🐇📄 パス❗️` | ファイルの中身を全部読んで、データ（`📇`）で返す |

どちらも、うまくいかなかったときは `🚧🔸↕️`（入出力のエラー）を投げます（[エラー](../types/errors.md)）。エラーのメッセージは、C の `strerror` が返す文（`No such file or directory` など）です。この節のメソッドは、ほかのものもエラーを投げるときはすべて `🚧🔸↕️` です。

```keywords
ファイル
file
fstream
ofstream
ifstream
読み込み
書き込み
IOError
入出力エラー
```

### 開いて少しずつ読み書きする（📄）

`📻` と `📇` はファイル全体をまとめて扱います。ファイルを開いておき、位置を決めて書いたり、決まったバイト数だけ読んだりするときは、`📄` のインスタンスを作ります。書くために開いたファイルからは読めず、読むために開いたファイルには書けません。

```emojicode
📦 files 🏠

🏁 🍇
  🍺 🆕📄▶️📝 🔤log.txt🔤❗️ ➡️ out
  🍺 ✏️ out 📇 🔤abcdef🔤❗️❗️
  🔛 out 2❗️
  🍺 ✏️ out 📇 🔤XY🔤❗️❗️
  🚪 out❗️

  🍺 🆕📄▶️📜 🔤log.txt🔤❗️ ➡️ in
  🍺 📓 in 3❗️ ➡️ head
  😀 🍺 🔡 head❗️❗️
  🔛 in 4❗️
  🍺 📓 in 2❗️ ➡️ tail
  😀 🍺 🔡 tail❗️❗️
  🚪 in❗️
🍉
```

```output
abX
ef
```

| 書き方 | 意味 |
|---|---|
| `🆕📄▶️📝 パス❗️` | 書くために開く。ファイルがなければ作り、あれば中身を空にする |
| `🆕📄▶️📜 パス❗️` | 読むために開く |
| `✏️ ファイル データ❗️` | 今の位置にデータを書く |
| `📓 ファイル バイト数❗️` | 今の位置から、そのバイト数だけ読んでデータで返す |
| `🔛 ファイル 位置❗️` | 先頭から数えたバイトの位置に移る |
| `🔚 ファイル❗️` | 末尾に移る |
| `💧 ファイル❗️` | ためてある書き込みを、ファイルに書き出す |
| `🚪 ファイル❗️` | 閉じる。閉じた後に読み書きしてはいけない |

開く・書く・読むメソッドはエラーを投げることがあるので、`🍺` や `🆗` をつけて呼びます。`📓` は文字数ではなくバイト数で数えます。UTF-8 では日本語の 1 文字が 3 バイトなので、文字の途中で切れることがあります。

書いた内容は、すぐにはファイルに入りません。`💧` か `🚪` を呼ぶと書き出されます。`📄` のインスタンスが要らなくなって消えるときも、自動で `🚪` が呼ばれます（[片付けるときの処理](classes.md)）。

```emojicode
📦 files 🏠

🏁 🍇
  🍺 🆕📄▶️📝 🔤memo.txt🔤❗️ ➡️ out
  🍺 ✏️ out 📇 🔤こんにちは🔤❗️❗️
  😀 🔤[🧲🍺 🔡 🍺📇🐇📄 🔤memo.txt🔤❗️❗️🧲]🔤❗️
  💧 out❗️
  😀 🔤[🧲🍺 🔡 🍺📇🐇📄 🔤memo.txt🔤❗️❗️🧲]🔤❗️
  🚪 out❗️
🍉
```

```output
[]
[こんにちは]
```

`📓` で残りより多いバイト数を求めると、途中まで読めた分も返さずにエラーになります。一度読むのに失敗したファイルは、`🔛` で位置を戻しても、その後の読み込みがすべてエラーになります。読む量がわからないときは、`📏🕊📑`（下の節）で先に大きさを調べるか、`📇🐇📄` で全体を読みます。

```emojicode
📦 files 🏠

🏁 🍇
  🍺 📻🐇📄 🔤a.txt🔤 📇 🔤hello🔤❗️❗️
  🍺 🆕📄▶️📜 🔤a.txt🔤❗️ ➡️ in
  🆗 data 📓 in 10❗️ 🍇
    😀 🍺 🔡 data❗️❗️
  🍉
  🙅 error 🍇
    😀 🔤10 バイトは読めない🔤❗️
  🍉
  🔛 in 0❗️
  🆗 data 📓 in 1❗️ 🍇
    😀 🍺 🔡 data❗️❗️
  🍉
  🙅 error 🍇
    😀 🔤戻しても読めない🔤❗️
  🍉
🍉
```

```output
10 バイトは読めない
戻しても読めない
```

`🔛` で前に戻って書くと、そこにあった内容を上書きします。`🔚` で末尾に移れば、続けて書いた内容は後ろに足されます。

```emojicode
📦 files 🏠

🏁 🍇
  🍺 🆕📄▶️📝 🔤a.txt🔤❗️ ➡️ out
  🍺 ✏️ out 📇 🔤abcdef🔤❗️❗️
  🔛 out 0❗️
  🍺 ✏️ out 📇 🔤X🔤❗️❗️
  🔚 out❗️
  🍺 ✏️ out 📇 🔤Z🔤❗️❗️
  🚪 out❗️
  😀 🍺 🔡 🍺📇🐇📄 🔤a.txt🔤❗️❗️❗️
🍉
```

```output
XbcdefZ
```

公式コンパイラの `🔚` は、末尾ではなく先頭から 2 バイト進んだ位置（3 バイト目）に移るバグがあり、この IDE では直しています（[修正済みのバグ](../about/patched.md)）。

`files.🍇` には、標準出力・標準入力・標準エラーを `📄` として返す `📤` `📥` `📯` も書かれていますが、コメントになっていて使えません（[Emojicode言語のバグ](../about/known-issues.md)）。

### ディレクトリを作る・消す・調べる（📑）

`📑` は、ディレクトリを作ったり、ファイルがあるかを調べたりする型メソッドを集めた型です。値型（`🕊`）なので、`📁🕊📑 パス❗️` のように `🕊📑` と書いて呼びます。

```emojicode
📦 files 🏠

🏁 🍇
  🍺 📁🕊📑 🔤data🔤❗️
  🍺 📻🐇📄 🔤data/a.txt🔤 📇 🔤12345🔤❗️❗️
  ↪️ 📃🕊📑 🔤data/a.txt🔤❗️ 🍇
    😀 🔤ある🔤❗️
  🍉
  😀 🔡 🍺📏🕊📑 🔤data/a.txt🔤❗️❗️❗️
  🆗 🔥🕊📑 🔤data🔤❗️ 🍇
    😀 🔤消せた🔤❗️
  🍉
  🙅 error 🍇
    😀 💬 error❗️❗️
  🍉
  🍺 💣🕊📑 🔤data🔤❗️
  ↪️ ❎ 📃🕊📑 🔤data🔤❗️❗️ 🍇
    😀 🔤中身ごと消えた🔤❗️
  🍉
🍉
```

```output
ある
5
Directory not empty
中身ごと消えた
```

`🔥` などの値を返さないメソッドを `🆗` で受け止めるときは、`🆗` の後に名前を書きません。

| 書き方 | 意味 |
|---|---|
| `📁🕊📑 パス❗️` | ディレクトリを作る。親のディレクトリはあらかじめ必要 |
| `🔫🕊📑 パス❗️` | ファイルを消す（ドキュメントコメントではディレクトリに使わないことになっているが、空のディレクトリも消える） |
| `🔥🕊📑 パス❗️` | 空のディレクトリを消す |
| `💣🕊📑 パス❗️` | ディレクトリを、中のファイルやディレクトリごと消す |
| `🔗🕊📑 元のパス リンクのパス❗️` | シンボリックリンクを作る |
| `📃🕊📑 パス❗️` | ファイルかディレクトリがあるか（`👌`） |
| `📜🕊📑 パス❗️` | あって、読めるか（`👌`） |
| `📝🕊📑 パス❗️` | あって、書けるか（`👌`） |
| `👟🕊📑 パス❗️` | あって、実行できるか（`👌`） |
| `📏🕊📑 パス❗️` | ファイルの大きさ（バイト数） |
| `⛓🕊📑 パス❗️` | `.` や `..`、シンボリックリンクをたどった絶対パス |

`📃` `📜` `📝` `👟` 以外は、エラーを投げることがあります。`📏` は、`files.🍇` のコメントには「見つからなければ -1 を返す」とありますが、実際にはエラーを投げます。

この IDE の仮想のファイルシステムでは、次のように本物の OS と動きが違います。プログラムが始まったときのディレクトリは `/` で、ファイルは最初は何もありません。`📁` は、すでにあるディレクトリを渡してもエラーになりません。`📜` と `📝` はいつも `👎`、`👟` はあるものなら何でも `👍` を返します。`🔗` はいつも、`⛓` は `/` を指すパス（`.` や `/` など）以外では、`Not supported` のエラーになります。`💣` にファイルを渡すと、そのファイルを消します。

## JSON を読む（📦 json）

`json` パッケージは、JSON の文字列を読んで Emojicode の値にします（JSON を書き出す機能はありません）。結果は `⚪️`（どんな型でもよい値）なので、`🔲` で型を確かめて取り出します（[キャスト](../types/casting.md)）。

```emojicode
📦 json 🏠

🏁 🍇
  🍺 ⚪️🕊🌸 🔤[1, 2.5, "a", true, null, [], {}]🔤❗️ ➡️ value
  🍺 🔲 value 🍨🐚⚪️🍆 ➡️ list
  🔂 item list 🍇
    ↪️ 🔲 item 🔢 ➡️ n 🍇
      😀 🔤🔢 🧲🔡 n❗️🧲🔤❗️
    🍉
    🙅↪️ 🔲 item 💯 ➡️ r 🍇
      😀 🔤💯 🧲🔡 r 1❗️🧲🔤❗️
    🍉
    🙅↪️ 🔲 item 🔡 ➡️ s 🍇
      😀 🔤🔡 🧲s🧲🔤❗️
    🍉
    🙅↪️ 🔲 item 👌 ➡️ b 🍇
      😀 🔤👌🔤❗️
    🍉
    🙅↪️ 🔲 item 🍨🐚⚪️🍆 ➡️ l 🍇
      😀 🔤🍨🔤❗️
    🍉
    🙅↪️ 🔲 item 🍯🐚⚪️🍆 ➡️ d 🍇
      😀 🔤🍯🔤❗️
    🍉
    🙅 🍇
      😀 🔤null🔤❗️
    🍉
  🍉
🍉
```

```output
🔢 1
💯 2.5
🔡 a
👌
null
🍨
🍯
```

| JSON | Emojicode の値 |
|---|---|
| 文字列 | `🔡` |
| 小数点も `e` `E` もない数 | `🔢`（`🔢` に収まらなければ `💯`） |
| 小数点か `e` `E` がある数 | `💯` |
| `true` `false` | `👌` |
| `null` | 値なし（`🤷‍♂️`）。どの型の `🔲` にも当てはまらない |
| 配列 | `🍨🐚⚪️🍆` |
| オブジェクト | `🍯🐚⚪️🍆` |

オブジェクトの値が `null` のとき、`🐽` で取り出すと、キーがないときと同じく値なしになります。2 つは区別できません。

| 書き方 | 意味 |
|---|---|
| `⚪️🕊🌸 文字列❗️` | 文字列を読んで、表している値を返す |
| `🆕🌸 文字列❗️` | 文字列を読むパーサーを作る |
| `🆕🌸▶️📇 データ❗️` | UTF-8 のデータ（`📇`）を読むパーサーを作る |
| `⚪️ パーサー❗️` | パーサーの入力を読んで、表している値を返す |

パーサーの `⚪️` は読んだ位置を進めるので、パーサーは `🖍🆕` で作った変数に入れておきます。ファイルから読んだデータは、`🆕🌸▶️📇` でそのまま渡せます。

```emojicode
📦 json 🏠

🏁 🍇
  🆕🌸▶️📇 📇 🔤"データ"🔤❗️❗️ ➡️ 🖍🆕 parser
  🆗 value ⚪️ parser❗️ 🍇
    ↪️ 🔲 value 🔡 ➡️ text 🍇
      😀 text❗️
    🍉
  🍉
  🙅 error 🍇
    😀 💬 error❗️❗️
  🍉
🍉
```

```output
データ
```

### 読めないとき（🚧🔸🌸）

JSON として正しくない文字列を渡すと、`⚪️` は `🚧🔸🌸` を投げます。`🚧` のサブクラスなので、`💬` でメッセージを取り出せます。

```emojicode
📦 json 🏠

🏁 🍇
  🍿 🔤{"a": 1,}🔤 🔤[1 2]🔤 🔤"abc🔤 🔤1 2🔤 🍆 ➡️ inputs
  🔂 text inputs 🍇
    🆗 value ⚪️🕊🌸 text❗️ 🍇
      😀 🔤読めた🔤❗️
    🍉
    🙅 error 🍇
      😀 💬 error❗️❗️
    🍉
  🍉
🍉
```

```output
Invalid JSON.
Expected ].
Unexpected end of input.
Unexpected input after end of value.
```

| メッセージ | 投げられるとき |
|---|---|
| `Unexpected end of input.` | 値が終わる前に入力が終わった（空の文字列、閉じていない `"`、`tru` など） |
| `Unexpected input after end of value.` | 値の後ろに、空白以外のものがある（`1 2`、`012` など） |
| `Invalid JSON.` | 値が始まるはずの場所に、値にならない文字がある（`'a'`、`"` のないキー、最後の要素の後ろの `,` など） |
| `Expected }.` | オブジェクトの値の後ろに、`,` も `}` もない |
| `Expected ].` | 配列の要素の後ろに、`,` も `]` もない |
| `Expected digit after decimal point` | 小数点の後ろに数字がない（`1.` など） |
| `Expected digit after minus sign` | `-` の後ろに数字がない（`-` だけ、`-x` など） |
| `Expected digit in exponent` | `e` `E` の後ろに数字がない（`1e`、`1e+` など） |
| `Unrecognized escape sequence.` | `\` の後ろが、JSON のエスケープにない文字（`\x` など） |
| `\u must be followed by four characters in range 0-9, A-F, a-f` | `\u` の後ろの 4 文字に、16 進数の数字でない文字がある（`\u00G1` など） |
| `\u sequence is begin of surrogate pair but not followed by another \u sequence` | サロゲートペアの前半（`\ud83d` など）の後ろに、後半の `\u` がない |

```emojicode
📦 json 🏠

🏁 🍇
  🍿 🔤-🔤 🔤"\u00G1"🔤 🔤"\u00e9"🔤 🍆 ➡️ inputs
  🔂 text inputs 🍇
    🆗 value ⚪️🕊🌸 text❗️ 🍇
      ↪️ 🔲 value 🔡 ➡️ s 🍇
        😀 s❗️
      🍉
    🍉
    🙅 error 🍇
      😀 💬 error❗️❗️
    🍉
  🍉
🍉
```

```output
Expected digit after minus sign
\u must be followed by four characters in range 0-9, A-F, a-f
é
```

公式コンパイラの `json` には、`-` だけの入力や `1e`、`\u` の後ろの `G`〜`Z` をエラーにせず読んでしまうバグと、数を読み違えるバグ（小数点のすぐ後ろの `0` が消えて `0.05` が `0.5` になる、`🔢` に収まらない `18446744073709551616` や、小数点の後ろの数字が 19 個以上ある数が壊れる）があり、この IDE では直しています（[修正済みのバグ](../about/patched.md)）。

```keywords

```

## テストを書く（📦 testtube）

`testtube` は、テストを書くためのパッケージです。

```emojicode
📦 testtube 🏠

🐇 🔬 🧪 🍇
```

### 確かめるメソッド

`🧪` のサブクラスを作り、`🏁` を `✒️` で上書きして、その中で次のメソッドを `👇` に対して呼びます。`👔` 以外は `🔐`（サブクラスの中からだけ呼べる）なので、`🧪` の外からは呼べません。`👔` はテストを動かすために外から呼びます。

| 書き方 | 意味 |
|---|---|
| `⛔👇 値 説明❗️` | 値が `👍` か |
| `❎👇 値 説明❗️` | 値が `👎` か |
| `🔡👇 値 期待する値 説明❗️` | 2 つの文字列が等しいか |
| `🔢👇 値 期待する値 説明❗️` | 2 つの整数が等しいか |
| `💧👇 値 期待する値 説明❗️` | 2 つのバイトが等しいか |
| `💯👇 値 期待する値 説明❗️` | 2 つの実数が等しいか（`🙌` で比べるので、誤差があると失敗する） |
| `✅👇 説明❗️` | 成功を 1 つ数える |
| `🙁👇 説明❗️` | 失敗を 1 つ数え、メッセージを出す |
| `👔 テスト❗️` | `🏁` を動かして結果を出し、失敗があれば `1`、なければ `0` を返す |

失敗すると、`❌ Failed 説明` の行が出ます。`🔡` `🔢` `💧` `💯` で失敗したときは、その後ろに実際の値が、`❎` では `but expected 👎` が続きます。期待する値は出ません。どの行も最後に空白が 1 つつきます。`✅` と `🙁` は、上の表のどれにも当てはまらない条件を自分で調べるときに使います。

```emojicode
📦 testtube 🏠

🐇 🔬 🧪 🍇
  ✒️ ❗️ 🏁 🍇
    🔡👇 🔤ab🔤 🔤abc🔤 🔤文字列🔤❗️
    💯👇 0.1 ➕ 0.2 0.3 🔤実数🔤❗️
    ❎👇 👍 🔤真🔤❗️
    ↪️ 📐 🔤abc🔤❗️ 🙌 3 🍇
      ✅👇 🔤長さ🔤❗️
    🍉
    🙅 🍇
      🙁👇 🔤長さ🔤❗️
    🍉
    🙁👇 🔤まだ書いていない🔤❗️
  🍉
🍉

🏁 🍇
  👔🆕🔬❗️❗️ ➡️ code
  😀 🔤終了コード 🧲🔡 code❗️🧲🔤❗️
🍉
```

```output
❌ Failed 文字列 but it is ab 
❌ Failed 実数 but it is 0.300000 
❌ Failed 真 but expected 👎  
❌ Failed まだ書いていない 
5 assertions, 4 failures
終了コード 1
```

`👔` の返す値を `🏁` から `↩️` で返すと（最初の例）、失敗があったときにプログラムの終了コードが 1 になります。`🏁` を上書きしないで `👔` を呼ぶと、`You might want to implement the 🏁 method.` と出ます。

## この IDE では使えないもの

- `📜 🔤ファイル名🔤` … 別のファイルを読み込む。この IDE はファイル 1 つだけをコンパイルするので使えません。
- `🌍` … 型を、パッケージの外に公開する。パッケージを作るときに使います。
- `📻`・`🔗` … C++ などで書いた関数とつなぐ。この IDE では使えません。

パッケージは、コンパイルしたコード（`lib名前.a`）と、`🏛` という名前のインターフェースファイルの 2 つでできています。`🏛` は、パッケージをビルドしたときにコンパイラが書き出す Emojicode のテキストで、`🌍` で公開した型とメソッドの宣言と、その `📗` のコメントが入っています。`📦` でパッケージを読み込むと、コンパイラはソースの代わりにこの `🏛` を読んで、使える型とメソッドを知ります。この IDE ではパッケージを作れないので `🏛` ができることはありませんが、読み込める `files` `json` `testtube` にも `🏛` があり、パッケージのメソッドの呼び方を間違えたときのエラーメッセージに `/packages/testtube/🏛:39:6` のような場所として出てきます。

```keywords
.h
```
