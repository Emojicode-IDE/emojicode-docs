# システムとスレッド

プログラムの外の世界（コマンドライン引数、環境変数、時刻など）とやりとりする `💻` と、スレッドの `🧵`、ミューテックスの `🔐` です。この IDE はブラウザの中で動いているので、本家をネイティブで動かしたときと動きが違うものがあります。

## プログラムの外とのやりとり（💻）

`💻` は型メソッドだけを持つクラスで、インスタンスは作れません。どれも `メソッド🐇💻 引数❗️` の形で呼びます。

| 書き方 | 意味 |
|---|---|
| `🎞🐇💻❗️` | コマンドライン引数のリスト（`🍨🐚🔡🍆`） |
| `🌳🐇💻 名前❗️` | 環境変数の値（`🍬🔡`）。なければ値なし |
| `🚪🐇💻 終了コード❗️` | その終了コードで、プログラムをすぐに終える |
| `🕰🐇💻❗️` | 今の時刻。1970 年 1 月 1 日 0 時（UTC）からの秒数 |
| `🕴🐇💻 コマンド❗️` | シェルでコマンドを実行する。この IDE では何もしない |
| `🤯🐇💻 メッセージ❗️` | メッセージを出して、プログラムを異常終了させる |

```keywords
💻
system
OS
オペレーティングシステム
```

### コマンドライン引数（🎞）

`🎞🐇💻❗️` は、プログラムに渡された引数を、プログラムの名前も含めてリストで返します。この IDE では引数を渡す方法がないので、中身はいつもプログラムの名前の `main` 1 つだけです。

```emojicode
🏁 🍇
  🎞🐇💻❗️ ➡️ args
  😀 🔤引数は 🧲🔡 📏 args❓❗️🧲 個🔤❗️
  🔂 arg args 🍇
    😀 arg❗️
  🍉
🍉
```

```output
引数は 1 個
main
```

```keywords
argv
argc
コマンドライン引数
引数
arguments
```

### 環境変数（🌳）

`🌳🐇💻 名前❗️` は、その名前の環境変数の値を返します。戻り値はオプショナルで、環境変数がなければ値なしです。この IDE では環境変数が 1 つも設定されていないので、いつも値なしになります。

```emojicode
🏁 🍇
  ↪️ 🌳🐇💻 🔤HOME🔤❗️ ➡️ home 🍇
    😀 home❗️
  🍉
  🙅 🍇
    😀 🔤HOME は設定されていない🔤❗️
  🍉
🍉
```

```output
HOME は設定されていない
```

```keywords
getenv
環境変数
environment variable
```

### 途中で終わる（🚪）

`🚪🐇💻 終了コード❗️` は、その場でプログラムを終えます。後ろの処理は実行されません。この IDE では、渡した終了コードが、実行のあとに表示されます。

```emojicode
🏁 🍇
  😀 🔤ここまで実行される🔤❗️
  🚪🐇💻 0❗️
  😀 🔤ここは実行されない🔤❗️
🍉
```

```output
ここまで実行される
```

本家の `💻.🍇` のコメントにあるとおり、たいていの OS では、終了コードは 255 までしか使えません。この IDE では、256 や -1 を渡しても、その数がそのまま表示されます。

```keywords
exit
std::exit
終了コード
終了
exit code
```

### 時刻（🕰）

`🕰🐇💻❗️` は、1970 年 1 月 1 日 0 時（UTC）からの秒数を整数で返します。C の `time(0)` と同じものです。この IDE でも、実際の今の時刻が返ります。

```emojicode
🏁 🍇
  🕰🐇💻❗️ ➡️ now
  ↪️ now ▶️ 1700000000 🍇
    😀 🔤2023 年 11 月より後🔤❗️
  🍉
🍉
```

```output
2023 年 11 月より後
```

秒より細かい時刻を取るメソッドはありません。

```keywords

```

### シェルのコマンド（🕴）

本家をネイティブで動かすと、`🕴🐇💻 コマンド❗️` は、コマンドをシェルで実行します（C の `system`）。コマンドの出力は、プログラムの出力にそのまま混ざります。`💻.🍇` のコメントには「標準出力を返す」とありますが、宣言に戻り値はなく、何も返しません。

この IDE ではコマンドを実行できないので、何もしません。

```emojicode
🏁 🍇
  🕴🐇💻 🔤echo こんにちは🔤❗️
  😀 🔤コマンドのあと🔤❗️
🍉
```

```output この IDE の実行結果
コマンドのあと
```

```keywords
system
シェル
shell
コマンド
command
```

### パニック（🤯）

`🤯🐇💻 メッセージ❗️` は、`🤯 Program panicked: メッセージ` と出力して、プログラムを異常終了させます。この IDE では、終了コードの代わりに「異常終了」と表示されます。続けられないほどおかしなことが起きたときに使います。続けられる失敗には、エラー（[エラー処理](../types/errors.md)）を使います。

```emojicode norun
🏁 🍇
  😀 🔤始め🔤❗️
  🤯🐇💻 🔤ありえない状態🔤❗️
  😀 🔤ここは実行されない🔤❗️
🍉
```

この例を実行すると、出力は次のとおりになり、異常終了します。

```text
始め
🤯 Program panicked: ありえない状態
```

```keywords
panic
abort
パニック
異常終了
```

## 処理されていないエラー（🚧 の 🤯）

`🚧` にも `🤯 場所❗️` というメソッドがあります。`🍺` をつけて呼んだメソッドがエラーを投げたときに、実行時がこれを呼び、プログラムを止めます（[必ず成功するとわかっているとき](../types/errors.md)）。中身は `💻` の `🤯` を呼ぶだけで、メッセージは `Unhandled error at 場所: エラーのメッセージ` になります。この IDE では、場所は `/work/main.🍇:行:列` の形です。

`🔏` のついたメソッドなので、サブクラスで書き換えることはできません。自分で呼ぶこともできますが、ふつうは使いません。

```keywords
unhandled error
処理されていないエラー
🍺
```

## スレッド（🧵）

本家をネイティブで動かすと、`🆕🧵 クロージャ❗️` は新しいスレッドを作り、そのスレッドでクロージャを実行します。作ったほうの処理は、クロージャの終わりを待たずに先へ進みます。クロージャは作った場所より長く使われるので、`🍇🎍🥡` と書きます（[外に持ち出すクロージャ](../types/closures.md)）。

| 書き方 | 意味 |
|---|---|
| `🆕🧵 クロージャ❗️` | 新しいスレッドで、クロージャを実行する |
| `🛂 スレッド❗️` | そのスレッドが終わるまで待つ（join） |
| `⏲🐇🧵 マイクロ秒❗️` | 今のスレッドを、少なくともそのマイクロ秒だけ止める |

この IDE にはスレッドがありません。`🆕🧵` は、渡したクロージャをその場で最後まで実行してから戻ります。そのため、`🛂` は何もしません。下の例は、ネイティブなら「作ったあと」と「スレッドの中」のどちらが先に出るか決まっていませんが、この IDE ではいつもこの順になります。

```emojicode
🏁 🍇
  🆕🧵 🍇🎍🥡
    😀 🔤スレッドの中🔤❗️
  🍉❗️ ➡️ thread
  😀 🔤作ったあと🔤❗️
  🛂 thread❗️
  😀 🔤終わり🔤❗️
🍉
```

```output この IDE の実行結果
スレッドの中
作ったあと
終わり
```

`⏲` は、この IDE でも実際に止まります。次の例は 1.5 秒止まり、その前後の時刻の差が 1 秒以上あることを確かめています。なお、この IDE では実行が 10 秒で打ち切られ、止まっている間も数えられます。

```emojicode
🏁 🍇
  🕰🐇💻❗️ ➡️ before
  ⏲🐇🧵 1500000❗️
  ↪️ 🕰🐇💻❗️ ➖ before ▶️🙌 1 🍇
    😀 🔤1 秒以上たった🔤❗️
  🍉
🍉
```

```output
1 秒以上たった
```

```keywords
thread
std::thread

sleep

スレッド
並行
待つ
```

## ミューテックス（🔐）

ミューテックスは、いくつかのスレッドが同じデータを触るとき、一度に 1 つのスレッドだけが触るようにするためのものです。本家をネイティブで動かすと、`🔒` はほかのスレッドがロックしている間は待ち、`🔐` は待たずに、ロックできたら 👍、できなかったら 👎 を返します。

| 書き方 | 意味 |
|---|---|
| `🆕🔐❗️` | ミューテックスを作る |
| `🔒 ミューテックス❗️` | ロックする。ほかのスレッドがロックしていたら、解除されるまで待つ |
| `🔓 ミューテックス❗️` | ロックを解除する |
| `🔐 ミューテックス❗️` | ロックを試す。ロックできたかどうかを `👌` で返す |

次の例では、3 つのスレッドが 1 つのカウンターに足します。`🔒` と `🔓` で囲むと、ネイティブでも足し算が混ざりません。

```emojicode
🐇 🧮 🍇
  🖍🆕 total 🔢 ⬅️ 0
  🆕 🍇🍉
  ❗️ 🎒 n 🔢 🍇
    total ⬅️➕ n
  🍉
  ❗️ 📤 ➡️ 🔢 🍇
    ↩️ total
  🍉
🍉

🏁 🍇
  🆕🧮❗️ ➡️ counter
  🆕🔐❗️ ➡️ lock
  🆕🍨🐚🧵🍆❗️ ➡️ 🖍🆕 threads
  🔂 i 🆕⏩ 1 4❗️ 🍇
    🐻 threads 🆕🧵 🍇🎍🥡
      🔒 lock❗️
      🎒 counter i❗️
      🔓 lock❗️
    🍉❗️❗️
  🍉
  🔂 thread threads 🍇
    🛂 thread❗️
  🍉
  😀 🔡 📤 counter❗️❗️❗️
🍉
```

```output
6
```

この IDE ではスレッドが取り合うことがないので、`🔒` と `🔓` は何もしません。`🔐` はいつも 👍 を返します。すでに `🔒` でロックしていても同じです。

```emojicode
🏁 🍇
  🆕🔐❗️ ➡️ lock
  🔒 lock❗️
  ↪️ 🔐 lock❗️ 🍇
    😀 🔤ロックできた🔤❗️
  🍉
  🙅 🍇
    😀 🔤ロックできなかった🔤❗️
  🍉
  🔓 lock❗️
🍉
```

```output この IDE の実行結果
ロックできた
```

ネイティブでは、ほかのスレッドがロックしている間は 👎 になります。なお、公式コンパイラの `🔐` はロックできたかどうかを返さないバグがあり、この IDE では直しています（[`🔐` が、ミューテックスをロックできたかどうかを返さない](../about/patched.md#🔐-がミューテックスをロックできたかどうかを返さない)）。

```keywords
mutex
std::mutex
lock
unlock
try_lock
ミューテックス
ロック

```
