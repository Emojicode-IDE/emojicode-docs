# リストと辞書

## リスト（🍿・🍨）

リストは、同じ型の値を順番に並べたものです。`🍿 値 値 … 🍆` で作ります。型は `🍨🐚要素の型🍆` と書きます（たとえば整数のリストは `🍨🐚🔢🍆`）。

```emojicode
🏁 🍇
  🍿 10 20 30 🍆 ➡️ numbers
  😀 🔡 🐽 numbers 0❗️❗️❗️
  😀 🔡 📏 numbers❓❗️❗️
🍉
```

```output
10
3
```

| 書き方 | 意味 |
|---|---|
| `🐽 リスト 位置❗️` | その位置の要素（位置は 0 から） |
| `📏 リスト❓` | 要素の数 |

`📏` だけ `❗️` ではなく `❓` で閉じます。値を「問い合わせる」メソッドは `❓` で呼ぶ、という決まりがあります。

範囲の外を `🐽` で取ろうとすると、プログラムはそこで止まります。

### 書き換える

リストを書き換えるときは、変数を `🖍🆕` で作っておきます。

```emojicode
🏁 🍇
  🍿 🔤a🔤 🔤b🔤 🍆 ➡️ 🖍🆕 letters
  🐻 letters 🔤c🔤❗️
  🔤B🔤 ➡️ 🐽letters 1❗️
  🔂 l letters 🍇
    👄 l❗️
  🍉
  😀 🔤🔤❗️
🍉
```

```output
aBc
```

| 書き方 | 意味 |
|---|---|
| `🐻 リスト 値❗️` | 最後に足す |
| `値 ➡️ 🐽リスト 位置❗️` | その位置を書き換える |
| `🐨 リスト 位置❗️` | その位置の要素を取り除く |
| `🐼 リスト❗️` | 最後の要素を取り出して取り除く（`🍬`） |

`⬅️➕` などの演算つきの代入（[値と変数](values.md)）は、リストの要素には使えません。計算してから `➡️` で入れ直します（`🐽 list 1❗️ ➕ 10 ➡️ 🐽list 1❗️`）。

```emojicode error
🏁 🍇
  🍿 1 2 3 🍆 ➡️ 🖍🆕 list
  🐽 list 1❗️ ⬅️➕ 10
🍉
```

空のリストは `🆕🍨🐚要素の型🍆❗️` で作ります。

```emojicode

  🆕🍨🐚🔢🍆❗️ ➡️ 🖍🆕 squares
  🔂 i 🆕⏩ 1 6❗️ 🍇
    🐻 squares i ✖️ i❗️
  🍉
  🔂 s squares 🍇
    👄 🔤🧲🔡 s❗️🧲 🔤❗️
  🍉
  😀 🔤🔤❗️
🍉
```

```output

```

### 同じ値を並べる

`🆕🍨🐚要素の型🍆 値 個数❗️` で、同じ値を個数だけ並べたリストを作れます。大きさの決まった表を作るときに使います。

```emojicode
🏁 🍇
  🆕🍨🐚🔢🍆 0 5❗️ ➡️ 🖍🆕 counts
  3 ➡️ 🐽counts 2❗️
  😀 🆕🔡 🐰 counts 🍇 n 🔢 ➡️ 🔡 ↩️ 🔡 n❗️ 🍉❗️ 🔤 🔤❗️❗️
  🆕🍨🐚🔡🍆 🔤x🔤 3❗️ ➡️ marks
  😀 🆕🔡 marks 🔤,🔤❗️❗️
🍉
```

```output
0 0 3 0 0
x,x,x
```

引数は値が先、個数が後です。個数だけを渡す書き方（`🆕🍨🐚🔢🍆 5❗️`）はありません。

### コピーされる

リストは値型です（[値型と列挙型](../types/valuetypes.md)）。代入しても、メソッドや初期化子に渡しても、インスタンス変数にしまっても、中身がコピーされます。辞書も同じです。

```emojicode
🐇 📦 🍇
  🖍🆕 items 🍨🐚🔢🍆
  🆕 🍼 items 🍨🐚🔢🍆 🍇🍉
  ❗️ 📏 ➡️ 🔢 🍇
    ↩️ 📏 items❓
  🍉
🍉

🏁 🍇
  🍿 1 2 🍆 ➡️ 🖍🆕 a
  a ➡️ 🖍🆕 b
  🐻 b 3❗️
  😀 🔤a: 🧲🔡 📏 a❓❗️🧲、b: 🧲🔡 📏 b❓❗️🧲🔤❗️
  🆕📦 a❗️ ➡️ box
  🐻 a 4❗️
  😀 🔡 📏 box❗️❗️❗️
🍉
```

```output
a: 2、b: 3
2
```

`b` に足しても `a` は変わりません。`box` にしまったあとで `a` に足しても、`box` の中は 2 つのままです。

メソッドの引数は定数なので、受け取ったリストに `🐻` することもできません。メソッドの中でリストを書き換えたいときは、書き換えたリストを `↩️` で返すか、リストをインスタンス変数にして、そのクラスのメソッドから書き換えます。

```emojicode error
🐇 🧰 🍇
  🐇❗️ 🖊 list 🍨🐚🔢🍆 🍇
    🐻 list 5❗️
  🍉
🍉

🏁 🍇
  🆕🍨🐚🔢🍆❗️ ➡️ a
  🖊🐇🧰 a❗️
🍉
```

### リストのリスト

`🍨🐚🍨🐚🔢🍆🍆` のように、リストを要素にもつリストも作れます。中のリストは、`🐽` の結果に直接 `🐻` したり、`🐽` を 2 つ重ねた位置に `➡️` で入れたりすると、その場で書き換えられます。

```emojicode

  🍿 🍿 1 2 🍆 🍿 3 🍆 🍆 ➡️ 🖍🆕 grid
  🐻 🐽 grid 1❗️ 4❗️
  9 ➡️ 🐽🐽 grid 0❗️ 1❗️
  🔂 row grid 🍇
    😀 🆕🔡 🐰 row 🍇 n 🔢 ➡️ 🔡 ↩️ 🔡 n❗️ 🍉❗️ 🔤 🔤❗️❗️
  🍉
🍉
```

```output
1 9
3 4
```

### 並べ替え・変換・絞り込み

リストには、クロージャ（[クロージャ](../types/closures.md)）を渡して使うメソッドもあります。

```emojicode
🏁 🍇
  🍿 5 3 8 1 🍆 ➡️ 🖍🆕 list
  🦁 list 🍇 a 🔢 b 🔢 ➡️ 🔢 ↩️ a ➖ b 🍉❗️
  🐰 list 🍇 n 🔢 ➡️ 🔡 ↩️ 🔡 n❗️ 🍉❗️ ➡️ texts
  😀 🆕🔡 texts 🔤, 🔤❗️❗️
  🐭 list 🍇 n 🔢 ➡️ 👌 ↩️ n ▶️ 2 🍉❗️ ➡️ big
  😀 🔡 📏 big❓❗️❗️
🍉
```

```output
1, 3, 5, 8
3
```

| 書き方 | 意味 |
|---|---|
| `🦁 リスト 比べ方❗️` | 並べ替える（比べ方は、`a` が先なら負、同じなら 0、後なら正を返すクロージャ） |
| `🐰 リスト 変換❗️` | 各要素を変換した新しいリスト（map） |
| `🐭 リスト 条件❗️` | 条件に合う要素だけの新しいリスト（filter） |
| `🆕🔡 文字列のリスト 区切り❗️` | 区切りでつないだ 1 つの文字列（join） |

## 辞書（🍯）

辞書は、文字列のキーに値を結びつけたものです（キーは `🔡` だけです）。`🍿 キー ➡️ 値 … 🍆` で作ります。型は `🍯🐚値の型🍆` です。

```emojicode
🏁 🍇
  🍿 🔤りんご🔤 ➡️ 120 🔤みかん🔤 ➡️ 80 🍆 ➡️ 🖍🆕 prices
  ↪️ 🐽 prices 🔤みかん🔤❗️ ➡️ price 🍇
    😀 🔤みかんは 🧲🔡 price❗️🧲 円🔤❗️
  🍉
  150 ➡️ 🐽prices 🔤ぶどう🔤❗️
  😀 🔡 📏 prices❓❗️❗️
  ↪️ 🐣 prices 🔤バナナ🔤❗️ 🍇
    😀 🔤バナナはある🔤❗️
  🍉
  🙅 🍇
    😀 🔤バナナはない🔤❗️
  🍉
🍉
```

```output
みかんは 80 円
3
バナナはない
```

`🐽 辞書 キー❗️` は、キーがないこともあるので、オプショナル（`🍬`）を返します。`↪️ … ➡️ 名前` で取り出します（[オプショナル](optionals.md)）。

| 書き方 | 意味 |
|---|---|
| `🐽 辞書 キー❗️` | 値（`🍬`。キーがなければ値なし） |
| `値 ➡️ 🐽辞書 キー❗️` | キーに値を入れる（あれば上書き） |
| `🐣 辞書 キー❗️` | キーがあるか（`👌`） |
| `🐨 辞書 キー❗️` | キーを取り除く |
| `🐙 辞書❗️` | キーのリスト |
| `📏 辞書❓` | 項目の数 |
