# 条件分岐

## ↪️ もし

`↪️ 条件 🍇 … 🍉` は、条件が `👍`（真）のときだけブロックを実行します。

```emojicode
🏁 🍇
  18 ➡️ age
  ↪️ age ▶️🙌 18 🍇
    😀 🔤大人です🔤❗️
  🍉
🍉
```

```output
大人です
```

```keywords
if
もし
条件
```

## 🙅 そうでなければ

`🙅 🍇 … 🍉` を続けると、条件が `👎` のときに実行されます。条件をさらに重ねるときは `🙅↪️` を使います。

```emojicode
🏁 🍇
  72 ➡️ score
  ↪️ score ▶️🙌 80 🍇
    😀 🔤A🔤❗️
  🍉
  🙅↪️ score ▶️🙌 60 🍇
    😀 🔤B🔤❗️
  🍉
  🙅 🍇
    😀 🔤C🔤❗️
  🍉
🍉
```

```output
B
```

上から順に条件を見て、最初に当てはまったブロックだけが実行されます。

```keywords

そうでなければ
```

## 比べる

| 書き方 | 意味 |
|---|---|
| `a 🙌 b` | 等しい |
| `a ◀️ b` | より小さい |
| `a ▶️ b` | より大きい |
| `a ◀️🙌 b` | 以下 |
| `a ▶️🙌 b` | 以上 |

「等しくない」は、`🙌` の結果を `❎` で打ち消して書きます。

```emojicode
🏁 🍇
  3 ➡️ n
  ↪️ ❎ n 🙌 0❗️ 🍇
    😀 🔤0 ではない🔤❗️
  🍉
🍉
```

```output
0 ではない
```

`❎ … ❗️` は「中身の真偽を逆にする」メソッドの呼び出しです。

## 条件を組み合わせる

`🤝` は「かつ」、`👐` は「または」です。

```emojicode
🏁 🍇
  25 ➡️ temperature
  👍 ➡️ sunny
  ↪️ temperature ▶️🙌 20 🤝 sunny 🍇
    😀 🔤散歩日和🔤❗️
  🍉
  ↪️ temperature ◀️ 0 👐 temperature ▶️ 35 🍇
    😀 🔤外は危ない🔤❗️
  🍉
  🙅 🍇
    😀 🔤ふつうの日🔤❗️
  🍉
🍉
```

```output
散歩日和
ふつうの日
```

`🤝` は左が `👎` なら右を見ません。`👐` は左が `👍` なら右を見ません。

```keywords
&&
||
and
or
かつ
または
論理演算
短絡評価
```

## 条件は 👌 だけ

`↪️` の条件には、真偽値（`👌`）しか書けません。数や文字列をそのまま書くとコンパイルエラーになります。

```emojicode error
🏁 🍇
  1 ➡️ n
  ↪️ n 🍇
    😀 🔤1🔤❗️
  🍉
🍉
```
