# 条件分岐

## ↪️ もし

`↪️ 条件 🍇 … 🍉` は、条件が `👍`（真）のときだけブロックを実行します。

```emojicode
🏁 🍇
  18 ➡️ age
  ↪️ age ▶️🙌 18 🍇
    😀 🔤大人です🔤❗️
  🍉
🍉
```

```output
大人です
```

```keywords
if
もし
条件
```

## 🙅 そうでなければ

`🙅 🍇 … 🍉` を続けると、条件が `👎` のときに実行されます。条件をさらに重ねるときは `🙅↪️` を使います。

```emojicode
🏁 🍇
  72 ➡️ score
  ↪️ score ▶️🙌 80 🍇
    😀 🔤A🔤❗️
  🍉
  🙅↪️ score ▶️🙌 60 🍇
    😀 🔤B🔤❗️
  🍉
  🙅 🍇
    😀 🔤C🔤❗️
  🍉
🍉
```

```output
B
```

上から順に条件を見て、最初に当てはまったブロックだけが実行されます。

## 比べる

| 書き方 | 意味 |
|---|---|
| `a 🙌 b` | 等しい |
| `a ◀️ b` | より小さい |
| `a ▶️ b` | より大きい |
| `a ◀️🙌 b` | 以下 |
| `a ▶️🙌 b` | 以上 |

「等しくない」は、`🙌` の結果を `❎` で打ち消して書きます。

```emojicode
🏁 🍇
  3 ➡️ n
  ↪️ ❎ n 🙌 0❗️ 🍇
    😀 🔤0 ではない🔤❗️
  🍉
🍉
```

```output
0 ではない
```

`❎ … ❗️` は「中身の真偽を逆にする」メソッドの呼び出しです。

## 条件を組み合わせる

`🤝` は「かつ」、`👐` は「または」です。

```emojicode
🏁 🍇
  25 ➡️ temperature
  👍 ➡️ sunny
  ↪️ temperature ▶️🙌 20 🤝 sunny 🍇
    😀 🔤散歩日和🔤❗️
  🍉
  ↪️ temperature ◀️ 0 👐 temperature ▶️ 35 🍇
    😀 🔤外は危ない🔤❗️
  🍉
  🙅 🍇
    😀 🔤ふつうの日🔤❗️
  🍉
🍉
```

```output
散歩日和
ふつうの日
```

`🤝` は左が `👎` なら右を見ません。`👐` は左が `👍` なら右を見ません。

## 条件は 👌 だけ

`↪️` の条件には、真偽値（`👌`）しか書けません。数や文字列をそのまま書くとコンパイルエラーになります。

```emojicode error
🏁 🍇
  1 ➡️ n
  ↪️ n 🍇
    😀 🔤1🔤❗️
  🍉
🍉
```

## 起こりやすさを伝える（🎍🐌・🎍🏎）

`↪️` や `🙅↪️` の条件の後ろ、`🍇` の前に `🎍🐌` を書くと「この条件はめったに成り立たない」、`🎍🏎` を書くと「たいてい成り立つ」とコンパイラに伝えられます。`↪️ … ➡️ 名前` でオプショナルの中身を取り出すときにも書けます。

```emojicode
🏁 🍇
  🍿 3 0 7 🍆 ➡️ list
  🔂 n list 🍇
    ↪️ n 🙌 0 🎍🐌 🍇
      😀 🔤ゼロ🔤❗️
    🍉
    🙅↪️ n ▶️ 5 🎍🏎 🍇
      😀 🔤大きい🔤❗️
    🍉
    🙅 🍇
      😀 🔤小さい🔤❗️
    🍉
  🍉
  ↪️ 🔢 🔤12🔤 10❗️ ➡️ m 🎍🏎 🍇
    😀 🔡 m❗️❗️
  🍉
🍉
```

```output
小さい
ゼロ
大きい
12
```

結果は、書かないときと変わりません。コンパイラはこのヒントを LLVM の分岐の重み（`🎍🐌` なら成り立つ側が 1 対 99、`🎍🏎` なら 99 対 1）として機械語を作るときに渡すだけで、よく通る側の処理が速くなるように並べ方が変わることがある、という程度です。標準ライブラリでは、リストの範囲外の添字や容量の不足を調べる `↪️` に `🎍🐌` がついています。

書けるのは `↪️` と `🙅↪️` の条件の後ろだけです。`🙅` や `🔁` の後ろに書くと、`Expected BlockBegin but instead found Decorator(🐌).` というエラーになります。`🎍` に続けられるのは `🐌` と `🏎` だけで、ほかの絵文字も同じエラーになります。

```emojicode error
🏁 🍇
  1 ➡️ n
  🔁 n ◀️ 3 🎍🐌 🍇
    😀 🔤x🔤❗️
  🍉
🍉
```

```text
Expected BlockBegin but instead found Decorator(🐌).
```
