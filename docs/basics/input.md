# 標準入力

IDE では、プログラムが読む内容を **実行する前に** 「標準入力」タブに書いておきます。プログラムはそれを 1 行ずつ読みます（このドキュメントの例では、下の「標準入力」の内容を渡しています）。

## 1 行読む（👂🏼）

`🆕🔡▶️👂🏼❗️` で、標準入力から 1 行を文字列として読みます。行の終わりの改行は含みません。

```emojicode
🏁 🍇
  🆕🔡▶️👂🏼❗️ ➡️ name
  😀 🔤こんにちは、🧲name🧲 さん🔤❗️
🍉
```

```stdin
えもじ
```

```output
こんにちは、えもじ さん
```


## 数として読む

読んだ文字列を `🔢 … 10❗️` で整数に変えます。結果はオプショナル（`🍬🔢`）なので、`↪️ … ➡️` で取り出します（[オプショナル](optionals.md)）。

```emojicode
🏁 🍇
  🆕🔡▶️👂🏼❗️ ➡️ line
  ↪️ 🔢 line 10❗️ ➡️ n 🍇
    😀 🔤🧲line🧲 の 2 倍は 🧲🔡 n ✖️ 2❗️🧲🔤❗️
  🍉
  🙅 🍇
    😀 🔤数を入れてください🔤❗️
  🍉
🍉
```

```stdin
21
```

```output
21 の 2 倍は 42
```

## 1 行に並んだ数を読む

空白で区切られた数は、`🔫` で分けてから 1 つずつ変換します。

```emojicode
🏁 🍇
  🆕🔡▶️👂🏼❗️ ➡️ line
  0 ➡️ 🖍🆕 sum
  🔂 part 🔫 line 🔤 🔤❗️ 🍇
    ↪️ 🔢 part 10❗️ ➡️ n 🍇
      sum ⬅️➕ n
    🍉
  🍉
  😀 🔤合計 🧲🔡 sum❗️🧲🔤❗️
🍉
```

```stdin
3 1 4 1 5
```

```output
合計 14
```

## 何行も読む

最初の行に件数があって、続く行にデータがある、という形をよく使います。

```emojicode
🏁 🍇
  🍺 🔢 🆕🔡▶️👂🏼❗️ 10❗️ ➡️ count
  🔂 i 🆕⏩ 0 count❗️ 🍇
    🆕🔡▶️👂🏼❗️ ➡️ name
    😀 🔤🧲🔡 i ➕ 1❗️🧲: 🧲name🧲🔤❗️
  🍉
🍉
```

```stdin
3
アリス
ボブ
キャロル
```

```output
1: アリス
2: ボブ
3: キャロル
```

最初の行は必ず数だとわかっているので、`🍺` で取り出しています。数でない行を渡すと、プログラムはそこで止まります。
