# 繰り返し

## 🔂 決まった回数・範囲を回す

`🔂 名前 範囲 🍇 … 🍉` で、範囲の中の値を順に名前に入れながら、ブロックをくり返します。範囲は `🆕⏩ 始め 終わり❗️` で作ります。**終わりの値は含みません。**

```emojicode
🏁 🍇
  🔂 i 🆕⏩ 0 5❗️ 🍇
    😀 🔡 i❗️❗️
  🍉
🍉
```

```output
0
1
2
3
4
```

3 つ目の値を渡すと、その幅ずつ進みます。負の幅で数え下ろすこともできます。

```emojicode
🏁 🍇
  🔂 i 🆕⏩ 0 10 3❗️ 🍇
    👄 🔤🧲🔡 i❗️🧲 🔤❗️
  🍉
  😀 🔤🔤❗️
  🔂 i 🆕⏩ 3 0 -1❗️ 🍇
    👄 🔤🧲🔡 i❗️🧲 🔤❗️
  🍉
  😀 🔤🔤❗️
🍉
```

```output
0 3 6 9 
3 2 1 
```

```keywords
for
for文
range
範囲
カウンタ
```

## 🔂 リストを順に見る

`🔂` には、リスト（[リストと辞書](collections.md)）を渡すこともできます。

```emojicode
🏁 🍇
  🍿 🔤りんご🔤 🔤みかん🔤 🔤ぶどう🔤 🍆 ➡️ fruits
  🔂 fruit fruits 🍇
    😀 🔤🧲fruit🧲 が好き🔤❗️
  🍉
🍉
```

```output
りんご が好き
みかん が好き
ぶどう が好き
```

```keywords
foreach
for-in
範囲for
イテレーション
```

## 🔁 条件が成り立つあいだ

`🔁 条件 🍇 … 🍉` は、条件が `👍` のあいだブロックをくり返します。

```emojicode
🏁 🍇
  1 ➡️ 🖍🆕 n
  🔁 n ◀️ 100 🍇
    n ⬅️✖️ 2
  🍉
  😀 🔡 n❗️❗️
🍉
```

```output
128
```

```keywords
while
while文
無限ループ
```

## 途中で抜けたいとき

Emojicode には、ループを途中で抜ける `break` や、次の回に飛ばす `continue` にあたるものがありません。抜けたい条件をループの条件に入れるか、関数（メソッド）にして `↩️` で戻ります。

```emojicode
🏁 🍇
  💭 7 の倍数で、50 より大きい最初の数を探す
  1 ➡️ 🖍🆕 n
  👎 ➡️ 🖍🆕 found
  🔁 ❎ found❗️ 🍇
    n ⬅️➕ 1
    ↪️ n 🚮 7 🙌 0 🤝 n ▶️ 50 🍇
      👍 ➡️ 🖍found
    🍉
  🍉
  😀 🔡 n❗️❗️
🍉
```

```output
56
```

```keywords
break
continue
ループを抜ける
```
