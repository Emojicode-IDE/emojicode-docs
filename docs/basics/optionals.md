# オプショナル

## 値があるかもしれないし、ないかもしれない

文字列を数に変えるとき、辞書からキーで値を取るとき……「失敗するかもしれない」「見つからないかもしれない」ことがあります。そういう結果を表すのが **オプショナル** です。型は `🍬` を前につけて `🍬🔢` のように書きます。

値がないことは `🤷‍♀️` で表します。

```emojicode
🏁 🍇
  🔢 🔤123🔤 10❗️ ➡️ a
  🔢 🔤abc🔤 10❗️ ➡️ b
  ↪️ a 🙌 🤷‍♀️ 🍇
    😀 🔤a は値なし🔤❗️
  🍉
  ↪️ b 🙌 🤷‍♀️ 🍇
    😀 🔤b は値なし🔤❗️
  🍉
🍉
```

```output
b は値なし
```

## 中身を取り出す（↪️ … ➡️）

オプショナルのままでは計算に使えません。`↪️ オプショナル ➡️ 名前 🍇 … 🍉` と書くと、値があるときだけ、中身に名前をつけてブロックを実行します。

```emojicode
🏁 🍇
  ↪️ 🔢 🔤123🔤 10❗️ ➡️ n 🍇
    😀 🔡 n ✖️ 2❗️❗️
  🍉
  🙅 🍇
    😀 🔤数ではない🔤❗️
  🍉
🍉
```

```output
246
```

この書き方がいちばん安全です。値がないときの処理を `🙅` に書き忘れても、プログラムが止まることはありません。

## 必ずあるとわかっているとき（🍺）

`🍺 オプショナル` で、中身を直接取り出せます。ただし **値がなかったら、プログラムはそこで止まります。** 必ず値があると言い切れるときだけ使いましょう。

```emojicode
🏁 🍇
  🍺 🔢 🔤42🔤 10❗️ ➡️ n
  😀 🔡 n ➕ 1❗️❗️
🍉
```

```output
43
```

```keywords
!
```

## 自分で作る

関数（メソッド）の戻り値や変数の型を `🍬` つきにすると、値なしを入れられるようになります。

```emojicode
🏁 🍇
  🖍🆕 best 🍬🔢
  🤷‍♀️ ➡️ 🖍best
  🔂 n 🍿 3 9 4 🍆 🍇
    ↪️ best ➡️ b 🍇
      ↪️ n ▶️ b 🍇
        n ➡️ 🖍best
      🍉
    🍉
    🙅 🍇
      n ➡️ 🖍best
    🍉
  🍉
  ↪️ best ➡️ b 🍇
    😀 🔤いちばん大きいのは 🧲🔡 b❗️🧲🔤❗️
  🍉
🍉
```

```output
いちばん大きいのは 9
```
