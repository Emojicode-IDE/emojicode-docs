# 文字列

文字列は `🔤` で挟んで書きます。型は `🔡` です。

## 値を埋め込む（🧲）

文字列の中で `🧲` と `🧲` に挟んだところには、変数や式の値が入ります。

```emojicode
🏁 🍇
  🔤えもじ🔤 ➡️ name
  😀 🔤こんにちは、🧲name🧲 さん🔤❗️
  😀 🔤1 ➕ 2 は 🧲1 ➕ 2🧲🔤❗️
  😀 🔤半分は 🧲1.5🧲🔤❗️
🍉
```

```output
こんにちは、えもじ さん
1 ➕ 2 は 3
半分は 1.500000
```

`🧲` に入れられるのは、文字列にできる型の値です。文字列・整数・実数は入りますが、真偽値やリスト、オプショナルはそのままでは入りません。実数は小数点以下 6 桁まで出るので、桁を決めたいときは、下の「数との変換」の `🔡 実数 桁数❗️` で文字列にしてから入れます。

```emojicode error
🏁 🍇
  🔢 🔤12🔤 10❗️ ➡️ n
  😀 🔤n は 🧲n🧲🔤❗️
🍉
```

```text
is not compatible to
```

オプショナルは、中身を取り出してから入れます（[オプショナル](optionals.md)）。自分で作った型も、`❗️ 🔡 ➡️ 🔡` を用意してプロトコル `↘️🔸🔡` を守れば、`🧲` に入れられます（[プロトコル](../types/protocols.md)）。

## 数との変換

### 数 → 文字列

整数は `🔡 数❗️` で 10 進数の文字列になります。2 つ目の引数で基数（何進数か）を選べます。

```keywords
to_string
std::to_string
数値を文字列に
2進数
16進数
```

```emojicode
🏁 🍇
  😀 🔡 255❗️❗️
  😀 🔡 255 16❗️❗️
  😀 🔡 255 2❗️❗️
🍉
```

```output
255
ff
11111111
```

実数は `🔡 数 桁数❗️` で、小数点以下を何桁まで出すかを選びます。

```emojicode
🏁 🍇
  😀 🔡 2.5 1❗️❗️
  😀 🔡 2.5 3❗️❗️
🍉
```

```output
2.5
2.500
```

> 実数を文字列にするとき、指定した桁より下は **四捨五入ではなく切り捨て** になります（`🔡 3.05 2❗️` が `3.04` になることもあります）。公式コンパイラのバグです。詳しくは [Emojicode言語のバグ](../about/known-issues.md) を見てください。

### 文字列 → 数

`🔢 文字列 基数❗️` で、文字列を整数に変えます。

```keywords
stoi
stoll
std::stoi
atoi
parseInt
文字列を数値に
```

文字列が数として読めないこともあるので、結果は「整数か、値なし」を表す `🍬🔢`（オプショナル）になります。中身を取り出すには `↪️ … ➡️ 名前` を使います。

```emojicode
🏁 🍇
  ↪️ 🔢 🔤42🔤 10❗️ ➡️ n 🍇
    😀 🔡 n ➕ 1❗️❗️
  🍉
  ↪️ 🔢 🔤よんじゅうに🔤 10❗️ ➡️ n 🍇
    😀 🔤ここには来ない🔤❗️
  🍉
  🙅 🍇
    😀 🔤数ではなかった🔤❗️
  🍉
🍉
```

```output
43
数ではなかった
```

`↪️` と `🙅` は条件分岐（if と else）です。オプショナルは、のちの章でくわしく扱います。

### 文字 → 文字コード

`📇 文字列❗️` で、文字列を UTF-8 のバイト列（`📇`）にします。`🐽 バイト列 位置❗️` でその位置のバイト（`💧`）を取り出し、`🔢 バイト❗️` で整数にします。英数字や記号のような ASCII の文字は 1 バイトなので、これがそのまま文字コードになります。

```emojicode
🏁 🍇
  😀 🔡 🔢 🐽 📇 🔤A🔤❗️ 0❗️❗️❗️❗️
  🔂 c 🔤hello🔤 🍇
    💭 a を 0、b を 1、… とした番号
    👄 🔤🧲🔢 🐽 📇 c❗️ 0❗️❗️ ➖ 97🧲 🔤❗️
  🍉
  😀 🔤🔤❗️
🍉
```

```output
65
7 4 11 11 14 
```

`🔂 c 🔤hello🔤` は、文字列から 1 文字ずつ取り出すループです（下の「1 文字ずつ見る」）。

128 以上のバイトは、`🔢` にすると負の数になります。日本語や絵文字は 2 バイト以上で、どのバイトも 128 以上なので、この方法は ASCII の文字だけに使います。

番号から文字に戻すときは、`🔪 🔤abcdefghijklmnopqrstuvwxyz🔤 番号 1❗️` のように、並べた文字列から取り出します。

```keywords

```

### 探す（🔍・🕵️‍♀️）

`🔍` と `🕵️‍♀️` が返す位置は、`🔪` と違って UTF-8 のバイト数で数えます。ASCII の文字だけなら文字の位置と同じですが、`🔍 🔤あいう🔤 🔤う🔤❗️` は 2 ではなく 6 です。

`🕵️‍♀️` は、3 つ目の引数の位置（これもバイト単位）から後ろを探します。見つかった位置の次から探し直すと、出てくる場所を全部たどれます。

```emojicode
🏁 🍇
  🔤abcabcab🔤 ➡️ text
  0 ➡️ 🖍🆕 from
  👍 ➡️ 🖍🆕 more
  🔁 more 🍇
    ↪️ 🕵️‍♀️ text 🔤ab🔤 from❗️ ➡️ i 🍇
      👄 🔤🧲🔡 i❗️🧲 🔤❗️
      i ➕ 1 ➡️ 🖍from
    🍉
    🙅 🍇
      👎 ➡️ 🖍more
    🍉
  🍉
  😀 🔤🔤❗️
  ↪️ 🔍 🔤あいう🔤 🔤う🔤❗️ ➡️ i 🍇
    😀 🔡 i❗️❗️
  🍉
🍉
```

```output
0 3 6 
6
```

開始の位置が文字列のバイト数と同じかそれより大きいと、何も探さずに値なしを返します。

## 1 文字ずつ見る

`🔂 名前 文字列` で、文字列から見た目の 1 文字ずつを取り出せます（[繰り返し](loops.md)）。取り出した 1 文字も文字列（`🔡`）なので、`🙌` で 1 文字の文字列と比べます。

```emojicode
🏁 🍇
  🔂 c 🔤a🍎え👨‍👩‍👧🔤 🍇
    😀 🔤[🧲c🧲]🔤❗️
  🍉
  0 ➡️ 🖍🆕 ones
  🔂 c 🔤10110🔤 🍇
    ↪️ c 🙌 🔤1🔤 🍇
      ones ⬅️➕ 1
    🍉
  🍉
  😀 🔡 ones❗️❗️
🍉
```

```output
[a]
[🍎]
[え]
[👨‍👩‍👧]
3
```

文字列には、リストのように `🐽` で i 文字目を取るメソッドはありません。

```emojicode error
🏁 🍇
  😀 🐽 🔤abcde🔤 2❗️❗️
🍉
```

```text
has no suitable 🐽
```

i 文字目を何度も使うときは、`🎶 文字列❗️` で 1 文字ずつのリスト（`🍨🐚🔡🍆`）にしてから、`🐽` で取り出します。

```emojicode
🏁 🍇
  🎶 🔤abc🔤❗️ ➡️ chars
  😀 🐽 chars 1❗️❗️
  😀 🔡 📏 chars❓❗️❗️
🍉
```

```output

3
```

### 順番を比べる（↔️）

`↔️ 文字列 ほかの文字列❗️` は、2 つの文字列の順番を整数で返します。-1 なら前、0 なら同じ、1 なら後ろです。並べ替えの `🦁`（[リストと辞書](collections.md)）にそのまま渡せます。

ただし、この順番は辞書の順ではありません。まずバイト数を比べて、**長い文字列のほうを前** にします。バイト数が同じときだけ、先頭から 1 バイトずつ比べます。

```emojicode
🏁 🍇
  🍿 🔤pear🔤 🔤fig🔤 🔤apple🔤 🔤kiwi🔤 🍆 ➡️ 🖍🆕 fruits
  🦁 fruits 🍇 a 🔡 b 🔡 ➡️ 🔢 ↩️ ↔️ a b❗️ 🍉❗️
  😀 🆕🔡 fruits 🔤 🔤❗️❗️
  ↪️ ↔️ 🔤abc🔤 🔤abd🔤❗️ ◀️ 0 🍇
    😀 🔤abc が前🔤❗️
  🍉
🍉
```

```output
apple kiwi pear fig
abc が前
```

5 バイトの `apple` が先頭に、3 バイトの `fig` が最後に来ます。同じ 4 バイトの `kiwi` と `pear` は、`k` のほうが `p` より小さいので `kiwi` が前です。

公式コンパイラの `↔️` は、-1・0・1 ではなく、C の `memcmp` の結果をそのまま返すバグがあり（WebAssembly では最初に違ったバイトの差で、`🔤abc🔤` と `🔤abz🔤` なら -23）、この IDE では直しています（[修正済みのバグ](../about/patched.md)）。

### ハッシュ値（⚗️）

`⚗️ 文字列❗️` は、文字列のハッシュ値（`🔢`）を返します。同じ内容の文字列からは、同じプログラムの実行中ならいつも同じ値が出ます。辞書（`🍯`）も、キーの置き場所を決めるのにこの値を使っています。

```emojicode
🏁 🍇
  🔤emo🔤 ➡️ head
  ↪️ ⚗️ 🔤emoji🔤❗️ 🙌 ⚗️ 🔤🧲head🧲ji🔤❗️ 🍇
    😀 🔤同じハッシュ値🔤❗️
  🍉
🍉
```

```output
同じハッシュ値
```

値そのものは、実行するたびに変わります。計算の初めに、起動のたびにランダムに決める数を混ぜているからです。ファイルに保存して次の実行で比べる、といった使い方はできません。

```keywords

```

## 文字列を組み立てる（🔠）

`🔠` は、後ろに文字列を足していける入れ物です（ほかの言語の StringBuilder）。`🔡` は作ったあと変えられないので、`🔤🧲s🧲x🔤 ➡️ 🖍s` のように足していくと、そのたびに新しい文字列ができます。`🔠` は余裕をもった場所に書き足していくので、たくさん足しても速く済みます。

```emojicode
🏁 🍇
  🆕🔠❗️ ➡️ builder
  🔂 i 🆕⏩ 1 6❗️ 🍇
    🐻 builder 🔡 i❗️❗️
    ↪️ i ◀️ 5 🍇
      🐻 builder 🔤-🔤❗️
    🍉
  🍉
  😀 🔡 builder❗️❗️
  😀 🔡 📐 builder❗️❗️❗️
  🆕🔠▶️🔡 🔤えもじ🔤❗️ ➡️ name
  🐻 name 🔤こーど🔤❗️
  😀 🔤[🧲name🧲]🔤❗️
🍉
```

```output
1-2-3-4-5
9
[えもじこーど]
```

| 書き方 | 意味 |
|---|---|
| `🆕🔠❗️` | 空の `🔠` を作る（容量は 16 バイト） |
| `🆕🔠 容量❗️` | 容量（バイト数）を決めて、空の `🔠` を作る |
| `🆕🔠▶️🔡 文字列❗️` | その文字列から始まる `🔠` を作る |
| `🐻 🔠 文字列❗️` | 最後に文字列を足す |
| `📐 🔠❗️` | 中身の UTF-8 でのバイト数 |
| `🔡 🔠❗️` | 中身を文字列（`🔡`）にする |

`🔡` で作った文字列は中身のコピーなので、そのあと `🔠` に足しても変わりません。`🔠` はプロトコル `↘️🔸🔡` を守っているので、`🧲` にもそのまま入れられます。

1 文字の文字列を 1 つずつ足していったとき、`🧲` で毎回新しい文字列を作ると、2 万回で 0.6 秒ほど、3 万回で 3 秒ほどかかり、4 万回では 10 秒たっても終わりませんでした。`🔠` に `🐻` すると、100 万回でも 0.04 秒ほどです（どれも手元のパソコンで測った目安で、パソコンによって変わります）。

`🔠` はリストと違ってクラスです（[クラス](../types/classes.md)）。代入しても、メソッドに渡しても、同じ 1 つの `🔠` を指します。`🖍🆕` でない変数に入れていても `🐻` でき、受け取ったメソッドの中で足した文字列は、渡したほうからも見えます。

```emojicode
🐇 🖨 🍇
  🐇❗️ 🌟 out 🔠 n 🔢 🍇
    🔂 i 🆕⏩ 0 n❗️ 🍇
      🐻 out 🔤*🔤❗️
    🍉
  🍉
🍉

🏁 🍇
  🆕🔠❗️ ➡️ line
  🌟🐇🖨 line 3❗️
  🐻 line 🔤|🔤❗️
  🌟🐇🖨 line 2❗️
  😀 🔡 line❗️❗️
🍉
```

```output
***|**
```

### 安全でないメソッド

`🔠` には、`☣️ 🍇 … 🍉` の中でしか呼べないメソッドもあります（[安全でない処理（☣️）](../advanced/misc.md#安全でない処理☣️)）。

| 書き方 | 意味 |
|---|---|
| `🐺 🔠 メモリ 位置 バイト数❗️` | メモリ（`🧠`）の、その位置からバイト数だけを最後に足す |
| `🐻🔸💧 🔠 バイト❗️` | 1 バイト（`💧`）を最後に足す |
| `🐻🔸🔣 🔠 コードポイント❗️` | そのコードポイントの文字を最後に足す（コードポイントとして正しくなければ何もせず `👎` を返す） |

`🐺` と `🐻🔸💧` は、足したあとの中身が正しい UTF-8 になっているかを確かめません。正しくないバイトの並びになると、そのあとの動きは決まっていません。`🐻🔸🔣` は、負の数、サロゲート（`0xD800`〜`0xDFFF`）、`0x110000` 以上の数をはじきます。公式コンパイラはサロゲートを受けつけてしまうバグがあり、この IDE では直しています（[修正済みのバグ](../about/patched.md)）。

また、`🧠 文字列❗️` と `🧠 🔠❗️` は、中身を入れているメモリ（`🧠`）をコピーせずに返します。これ自体は `☣️` の外でも呼べますが、返ったメモリを読み書きするメソッドは、どれも `☣️` の中でしか使えません（[文字列とバイト列の中身（🧠）](../advanced/misc.md#文字列とバイト列の中身🧠)）。
