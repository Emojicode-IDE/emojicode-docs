# 文字列

文字列は `🔤` で挟んで書きます。型は `🔡` です。

## 値を埋め込む（🧲）

文字列の中で `🧲` と `🧲` に挟んだところには、変数や式の値が入ります。

```emojicode
🏁 🍇
  🔤えもじ🔤 ➡️ name
  😀 🔤こんにちは、🧲name🧲 さん🔤❗️
  😀 🔤1 ➕ 2 は 🧲1 ➕ 2🧲🔤❗️
  😀 🔤半分は 🧲1.5🧲🔤❗️
🍉
```

```output
こんにちは、えもじ さん
1 ➕ 2 は 3
半分は 1.500000
```

`🧲` に入れられるのは、文字列にできる型の値です。文字列・整数・実数は入りますが、真偽値やリスト、オプショナルはそのままでは入りません。実数は小数点以下 6 桁まで出るので、桁を決めたいときは、下の「数との変換」の `🔡 実数 桁数❗️` で文字列にしてから入れます。

```emojicode error
🏁 🍇
  🔢 🔤12🔤 10❗️ ➡️ n
  😀 🔤n は 🧲n🧲🔤❗️
🍉
```

```text
is not compatible to
```

オプショナルは、中身を取り出してから入れます（[オプショナル](optionals.md)）。自分で作った型も、`❗️ 🔡 ➡️ 🔡` を用意してプロトコル `↘️🔸🔡` を守れば、`🧲` に入れられます（[プロトコル](../types/protocols.md)）。


## 特別な文字（❌）

改行やタブ、`🔤` そのものなどを文字列の中に書くときは、前に `❌` をつけます。

```keywords
エスケープ
エスケープシーケンス
\n
\t
改行
タブ
```

| 書き方 | 意味 |
|---|---|
| `❌n` | 改行 |
| `❌t` | タブ |
| `❌🔤` | `🔤` という文字 |
| `❌🧲` | `🧲` という文字 |
| `❌❌` | `❌` という文字 |

```emojicode
🏁 🍇
  😀 🔤1 行目❌n2 行目🔤❗️
  😀 🔤❌🔤 で文字列、❌🧲 で埋め込み🔤❗️
🍉
```

```output
1 行目
2 行目
🔤 で文字列、🧲 で埋め込み
```

## 数との変換

### 数 → 文字列

整数は `🔡 数❗️` で 10 進数の文字列になります。2 つ目の引数で基数（何進数か）を選べます。

```keywords
to_string
std::to_string
数値を文字列に
2進数
16進数
```

```emojicode
🏁 🍇
  😀 🔡 255❗️❗️
  😀 🔡 255 16❗️❗️
  😀 🔡 255 2❗️❗️
🍉
```

```output
255
ff
11111111
```

実数は `🔡 数 桁数❗️` で、小数点以下を何桁まで出すかを選びます。

```emojicode
🏁 🍇
  😀 🔡 2.5 1❗️❗️
  😀 🔡 2.5 3❗️❗️
🍉
```

```output
2.5
2.500
```

> 実数を文字列にするとき、指定した桁より下は **四捨五入ではなく切り捨て** になります（`🔡 3.05 2❗️` が `3.04` になることもあります）。公式コンパイラのバグです。詳しくは [Emojicode言語のバグ](../about/known-issues.md) を見てください。

### 文字列 → 数

`🔢 文字列 基数❗️` で、文字列を整数に変えます。

```keywords
stoi
stoll
std::stoi
atoi
parseInt
文字列を数値に
```

文字列が数として読めないこともあるので、結果は「整数か、値なし」を表す `🍬🔢`（オプショナル）になります。中身を取り出すには `↪️ … ➡️ 名前` を使います。

```emojicode
🏁 🍇
  ↪️ 🔢 🔤42🔤 10❗️ ➡️ n 🍇
    😀 🔡 n ➕ 1❗️❗️
  🍉
  ↪️ 🔢 🔤よんじゅうに🔤 10❗️ ➡️ n 🍇
    😀 🔤ここには来ない🔤❗️
  🍉
  🙅 🍇
    😀 🔤数ではなかった🔤❗️
  🍉
🍉
```

```output
43
数ではなかった
```

`↪️` と `🙅` は条件分岐（if と else）です。オプショナルは、のちの章でくわしく扱います。

### 文字 → 文字コード

`📇 文字列❗️` で、文字列を UTF-8 のバイト列（`📇`）にします。`🐽 バイト列 位置❗️` でその位置のバイト（`💧`）を取り出し、`🔢 バイト❗️` で整数にします。英数字や記号のような ASCII の文字は 1 バイトなので、これがそのまま文字コードになります。

```emojicode
🏁 🍇
  😀 🔡 🔢 🐽 📇 🔤A🔤❗️ 0❗️❗️❗️❗️
  🔂 c 🔤hello🔤 🍇
    💭 a を 0、b を 1、… とした番号
    👄 🔤🧲🔢 🐽 📇 c❗️ 0❗️❗️ ➖ 97🧲 🔤❗️
  🍉
  😀 🔤🔤❗️
🍉
```

```output
65
7 4 11 11 14 
```

`🔂 c 🔤hello🔤` は、文字列から 1 文字ずつ取り出すループです（下の「1 文字ずつ見る」）。

128 以上のバイトは、`🔢` にすると負の数になります。日本語や絵文字は 2 バイト以上で、どのバイトも 128 以上なので、この方法は ASCII の文字だけに使います。

番号から文字に戻すときは、`🔪 🔤abcdefghijklmnopqrstuvwxyz🔤 番号 1❗️` のように、並べた文字列から取り出します。

```keywords

ASCII
ord
chr
char
c - 'a'
コードポイント
バイト
byte
```

## よく使うメソッド

```keywords

分割

```

| 書き方 | 結果 |
|---|---|
| `📫 文字列❗️` | 大文字にする |
| `📪 文字列❗️` | 小文字にする |
| `🔪 文字列 開始 長さ❗️` | 一部を取り出す（位置と長さは見た目の 1 文字単位） |
| `🔧 文字列❗️` | 前後の空白を取り除く |
| `🔫 文字列 区切り❗️` | 区切りで分けて、リスト（`🍨🐚🔡🍆`）にする |
| `🔍 文字列 探す文字列❗️` | 見つかった位置（`🍬🔢`） |
| `🎼 文字列 先頭❗️` / `⛳️ 文字列 末尾❗️` | その文字列で始まる / 終わるか（`👌`） |

```emojicode
🏁 🍇
  😀 📫 🔤emojicode🔤❗️❗️
  😀 🔪 🔤🍎🍌🍇🍑🔤 1 2❗️❗️
  😀 🔧 🔤  まわりの空白  🔤❗️❗️
  ↪️ 🎼 🔤🍇🍉🔤 🔤🍇🔤❗️ 🍇
    😀 🔤🍇 で始まる🔤❗️
  🍉
🍉
```

```output
EMOJICODE
🍌🍇
まわりの空白
🍇 で始まる
```

`🔪` の位置は 0 から数えます。`🍎🍌🍇🍑` の 1 番目から 2 文字なので `🍌🍇` です。絵文字が複数のコードポイントでできていても、見た目の 1 文字として数えます。

> `📐 文字列❗️` は文字数ではなく、UTF-8 での **バイト数** を返します。`📐 🔤えもじ🔤❗️` は 9 です。

```keywords

```

## 1 文字ずつ見る

`🔂 名前 文字列` で、文字列から見た目の 1 文字ずつを取り出せます（[繰り返し](loops.md)）。取り出した 1 文字も文字列（`🔡`）なので、`🙌` で 1 文字の文字列と比べます。

```emojicode
🏁 🍇
  🔂 c 🔤a🍎え👨‍👩‍👧🔤 🍇
    😀 🔤[🧲c🧲]🔤❗️
  🍉
  0 ➡️ 🖍🆕 ones
  🔂 c 🔤10110🔤 🍇
    ↪️ c 🙌 🔤1🔤 🍇
      ones ⬅️➕ 1
    🍉
  🍉
  😀 🔡 ones❗️❗️
🍉
```

```output
[a]
[🍎]
[え]
[👨‍👩‍👧]
3
```

文字列には、リストのように `🐽` で i 文字目を取るメソッドはありません。

```emojicode error
🏁 🍇
  😀 🐽 🔤abcde🔤 2❗️❗️
🍉
```

```text
has no suitable 🐽
```

i 文字目を何度も使うときは、`🎶 文字列❗️` で 1 文字ずつのリスト（`🍨🐚🔡🍆`）にしてから、`🐽` で取り出します。

```emojicode
🏁 🍇
  🎶 🔤abc🔤❗️ ➡️ chars
  😀 🐽 chars 1❗️❗️
  😀 🔡 📏 chars❓❗️❗️
🍉
```

```output
b
3
```

`🔪 文字列 i 1❗️` でも i 文字目を取れますが、`🔪` は毎回先頭から文字を数えるので、位置が後ろになるほど時間がかかります。長い文字列を `🔪` で 1 文字ずつ取り出すと、全体で文字数の 2 乗に比例する時間がかかり、4 万文字で 5 秒ほどになります。`🔂` や `🎶` なら、50 万文字でも 0.2 秒ほどです。

## 文字列の比較

`🙌` で、2 つの文字列が同じかどうかを比べます。

```keywords

```

```emojicode
🏁 🍇
  🔤abc🔤 ➡️ a
  ↪️ a 🙌 🔤abc🔤 🍇
    😀 🔤同じ🔤❗️
  🍉
🍉
```

```output
同じ
```
