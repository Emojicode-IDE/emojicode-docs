# 文字列

文字列は `🔤` で挟んで書きます。型は `🔡` です。

## 値を埋め込む（🧲）

文字列の中で `🧲` と `🧲` に挟んだところには、変数や式の値が入ります。

```emojicode
🏁 🍇
  🔤えもじ🔤 ➡️ name
  😀 🔤こんにちは、🧲name🧲 さん🔤❗️
  😀 🔤1 ➕ 2 は 🧲🔡 1 ➕ 2❗️🧲🔤❗️
🍉
```

```output
こんにちは、えもじ さん
1 ➕ 2 は 3
```

`🧲` の中に入れられるのは文字列だけです。数を入れるときは `🔡 … ❗️` で文字列にします。


## 特別な文字（❌）

改行やタブ、`🔤` そのものなどを文字列の中に書くときは、前に `❌` をつけます。

```keywords
エスケープ
エスケープシーケンス
\n
\t
改行
タブ
```

| 書き方 | 意味 |
|---|---|
| `❌n` | 改行 |
| `❌t` | タブ |
| `❌🔤` | `🔤` という文字 |
| `❌🧲` | `🧲` という文字 |
| `❌❌` | `❌` という文字 |

```emojicode
🏁 🍇
  😀 🔤1 行目❌n2 行目🔤❗️
  😀 🔤❌🔤 で文字列、❌🧲 で埋め込み🔤❗️
🍉
```

```output
1 行目
2 行目
🔤 で文字列、🧲 で埋め込み
```

## 数との変換

### 数 → 文字列

整数は `🔡 数❗️` で 10 進数の文字列になります。2 つ目の引数で基数（何進数か）を選べます。

```keywords
to_string
std::to_string
数値を文字列に
2進数
16進数
```

```emojicode
🏁 🍇
  😀 🔡 255❗️❗️
  😀 🔡 255 16❗️❗️
  😀 🔡 255 2❗️❗️
🍉
```

```output
255
ff
11111111
```

実数は `🔡 数 桁数❗️` で、小数点以下を何桁まで出すかを選びます。

```emojicode
🏁 🍇
  😀 🔡 2.5 1❗️❗️
  😀 🔡 2.5 3❗️❗️
🍉
```

```output
2.5
2.500
```

> 実数を文字列にするとき、指定した桁より下は **四捨五入ではなく切り捨て** になります（`🔡 3.05 2❗️` が `3.04` になることもあります）。公式コンパイラのバグです。詳しくは [Emojicode言語のバグ](../about/known-issues.md) を見てください。

### 文字列 → 数

`🔢 文字列 基数❗️` で、文字列を整数に変えます。

```keywords
stoi
stoll
std::stoi
atoi
parseInt
文字列を数値に
```

文字列が数として読めないこともあるので、結果は「整数か、値なし」を表す `🍬🔢`（オプショナル）になります。中身を取り出すには `↪️ … ➡️ 名前` を使います。

```emojicode
🏁 🍇
  ↪️ 🔢 🔤42🔤 10❗️ ➡️ n 🍇
    😀 🔡 n ➕ 1❗️❗️
  🍉
  ↪️ 🔢 🔤よんじゅうに🔤 10❗️ ➡️ n 🍇
    😀 🔤ここには来ない🔤❗️
  🍉
  🙅 🍇
    😀 🔤数ではなかった🔤❗️
  🍉
🍉
```

```output
43
数ではなかった
```

`↪️` と `🙅` は条件分岐（if と else）です。オプショナルは、のちの章でくわしく扱います。

## よく使うメソッド

```keywords
substr
部分文字列
find
toupper
tolower
大文字
小文字
trim
空白を除く
split
分割
starts_with
ends_with
```

| 書き方 | 結果 |
|---|---|
| `📫 文字列❗️` | 大文字にする |
| `📪 文字列❗️` | 小文字にする |
| `🔪 文字列 開始 長さ❗️` | 一部を取り出す（位置と長さは見た目の 1 文字単位） |
| `🔧 文字列❗️` | 前後の空白を取り除く |
| `🔫 文字列 区切り❗️` | 区切りで分けて、リスト（`🍨🐚🔡🍆`）にする |
| `🔍 文字列 探す文字列❗️` | 見つかった位置（`🍬🔢`） |
| `🎼 文字列 先頭❗️` / `⛳️ 文字列 末尾❗️` | その文字列で始まる / 終わるか（`👌`） |

```emojicode
🏁 🍇
  😀 📫 🔤emojicode🔤❗️❗️
  😀 🔪 🔤🍎🍌🍇🍑🔤 1 2❗️❗️
  😀 🔧 🔤  まわりの空白  🔤❗️❗️
  ↪️ 🎼 🔤🍇🍉🔤 🔤🍇🔤❗️ 🍇
    😀 🔤🍇 で始まる🔤❗️
  🍉
🍉
```

```output
EMOJICODE
🍌🍇
まわりの空白
🍇 で始まる
```

`🔪` の位置は 0 から数えます。`🍎🍌🍇🍑` の 1 番目から 2 文字なので `🍌🍇` です。絵文字が複数のコードポイントでできていても、見た目の 1 文字として数えます。

> `📐 文字列❗️` は文字数ではなく、UTF-8 での **バイト数** を返します。`📐 🔤えもじ🔤❗️` は 9 です。

```keywords
size
length
長さ
文字数
バイト数
```

## 文字列の比較

`🙌` で、2 つの文字列が同じかどうかを比べます。

```keywords
==
比較
等しい
同じ
```

```emojicode
🏁 🍇
  🔤abc🔤 ➡️ a
  ↪️ a 🙌 🔤abc🔤 🍇
    😀 🔤同じ🔤❗️
  🍉
🍉
```

```output
同じ
```
