# 値と変数

## 基本の型

Emojicode は静的型付きの言語で、すべての値に型があります。よく使うのはこの 4 つです。

| 型 | 意味 | 値の例 |
|---|---|---|
| `🔢` | 整数（64 ビット） | `42`、`-7`、`1,000,000`、`0x1F` |
| `💯` | 実数（浮動小数点数） | `3.14`、`-0.5` |
| `👌` | 真偽値 | `👍`（真）、`👎`（偽） |
| `🔡` | 文字列 | `🔤こんにちは🔤` |

整数は `,` で桁を区切って書けます。`0x` で始めると 16 進数です。

## 変数（定数）

`値 ➡️ 名前` で、値に名前をつけます。こうして作った変数は、あとから変えられない **定数** です。

```emojicode
🏁 🍇
  42 ➡️ answer
  😀 🔡 answer❗️❗️
🍉
```

```output
42
```

```keywords
const
定数
変数
auto
```

変数の名前は、英数字の普通の名前です。`😀` は文字列しか表示できないので、整数は `🔡 answer❗️` で文字列にしてから表示しています（[文字列](strings.md) で詳しく扱います）。

定数に別の値を入れようとすると、コンパイルエラーになります。

```emojicode error
🏁 🍇
  42 ➡️ answer
  43 ➡️ 🖍answer
🍉
```

```text
Cannot modify constant variable "answer".
```

## 変更できる変数

値をあとから変えたいときは、`➡️ 🖍🆕 名前` で **変更できる変数** を作ります。値を入れ直すときは `➡️ 🖍名前` です。

```emojicode
🏁 🍇
  0 ➡️ 🖍🆕 count
  😀 🔡 count❗️❗️
  5 ➡️ 🖍count
  😀 🔡 count❗️❗️
🍉
```

```output
0
5
```

```keywords
変数
代入
再代入
mutable
var
let
```

`🖍` は「書き換える」しるしだと覚えておくと読みやすくなります。`🖍🆕` が「書き換えられる変数を新しく作る」、`🖍` だけが「書き換える」です。

> 一度も書き換えない変数を `🖍🆕` で作ると、「定数にしたら？」という警告が出ます。動きはしますが、変えないものは `➡️ 名前` で作りましょう。

### 計算して入れ直す

`⬅️` と演算子を組み合わせると、「今の値に計算して入れ直す」を短く書けます。

```emojicode
🏁 🍇
  10 ➡️ 🖍🆕 score
  score ⬅️➕ 5
  score ⬅️✖️ 2
  😀 🔡 score❗️❗️
🍉
```

```output
30
```

`score ⬅️➕ 5` は `score ➕ 5 ➡️ 🖍score` と同じ意味です。`⬅️` だけで代入はできないので注意してください。

```keywords
+=
-=
*=
/=
複合代入
インクリメント
++
```

### 先に宣言して、あとで入れる

型を書いて先に宣言しておき、値はあとで入れることもできます。

```emojicode
🏁 🍇
  🖍🆕 message 🔡
  🔤あとで入れた🔤 ➡️ 🖍message
  😀 message❗️
🍉
```

```output
あとで入れた
```

## 計算

| 演算子 | 意味 |
|---|---|
| `➕` `➖` `✖️` `➗` | 足す・引く・かける・割る |
| `🚮` | 割った余り |

整数どうしの `➗` は、小数点以下を切り捨てます。実数で計算したいときは、片方を `💯` にしておきます。

```keywords
四則演算
足し算
引き算
掛け算
割り算
余り
剰余
%
modulo
static_cast
型変換
```

```emojicode
🏁 🍇
  😀 🔡 7 ➗ 2❗️❗️
  😀 🔡 7 🚮 2❗️❗️
  😀 🔡 7.0 ➗ 2.0 1❗️❗️
  😀 🔡 💯 7❗️ ➗ 2.0 1❗️❗️
🍉
```

```output
3
1
3.5
3.5
```

最後の行の `💯 7❗️` は、整数 `7` を実数に変えるメソッドの呼び出しです。`🔡 … 1❗️` の `1` は、小数点以下を何桁まで文字列にするかです。

計算の順番は、`✖️` `➗` が `➕` `➖` より先です。先に計算したいところは `🤜` と `🤛` で囲みます（ほかの言語の `(` `)` です）。

```keywords
括弧
()
優先順位
```

```emojicode
🏁 🍇
  😀 🔡 1 ➕ 2 ✖️ 3❗️❗️
  😀 🔡 🤜1 ➕ 2🤛 ✖️ 3❗️❗️
🍉
```

```output
7
9
```
