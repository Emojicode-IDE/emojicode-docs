# Emojicode Unofficial Reference

This is an unofficial reference for learning Emojicode. It is not affiliated with the Emojicode developers; it is written by an individual alongside this IDE.

[Emojicode](https://www.emojicode.org/) is a programming language in which almost every keyword and operator is an emoji. It is a statically typed language with classes, generics, closures, and error handling.

This reference is written so that you can read it while running the code. Press **▶ Run** at the top right of a code example to run it right on this page. Rewrite it with **✎ Edit** and run it again, and the output below changes to the new result.

```emojicode
🏁 🍇
  😀 🔤Welcome!🔤❗️
🍉
```

```output
Welcome!
```

## How to read

- If you are new, start with [Hello World](intro/hello.md). How to use the IDE is covered in [Using this IDE](about/ide.md).
- Every code example was actually compiled and run when this site was built, to confirm it produces exactly the output shown.
- The official documentation (in English) is [Emojicode Documentation](https://www.emojicode.org/docs/). This reference was written from scratch, separately from it, and its content is not official.

## Supported version

The Emojicode in this IDE is the official compiler's [`master`](https://github.com/emojicode/emojicode/tree/master) (commit [`4dec45b`](https://github.com/emojicode/emojicode/commit/4dec45b497e4f4dce7f5f5ae11a00d8e8e9af67c)) with changes to make it run on WebAssembly. Known bugs in the official compiler are listed in [Emojicode language bugs](about/known-issues.md), and the limitations of this IDE at the end of [Using this IDE](about/ide.md).
