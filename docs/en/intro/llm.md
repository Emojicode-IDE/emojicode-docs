# Docs for LLMs

This documentation is also available in a form that is easy for large language models to read. Having an LLM read it before you ask about Emojicode or have it write code can help make its answers more accurate.

## What to give it

Give it the following URL. It contains what you need to write Emojicode, in one file.

```copy URL
https://emojicode-ide.com/llms-full.txt
```

Its content is the same as this documentation, and every code example was actually compiled and run to check it.

## How to use it

At the start of a conversation, you can paste this prompt:

```copy Prompt to paste at the start of a chat
Please read the following material about Emojicode before answering.
https://emojicode-ide.com/llms-full.txt
```

If it cannot open URLs, you can also copy the file's contents and paste them in.

```copyfile /llms-full.txt
Copy the file's contents
```
