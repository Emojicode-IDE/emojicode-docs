# Emojicode 非公式リファレンス

Emojicode を日本語で学ぶための、非公式のリファレンスです。Emojicode の開発元とは関係なく、この IDE といっしょに個人で書いています。

[Emojicode](https://www.emojicode.org/) は、キーワードも演算子もほとんどが絵文字でできたプログラミング言語です。クラス、ジェネリクス、クロージャ、エラー処理をそなえた、静的型付けの言語です。

このドキュメントは、実際に動かしながら読めるように書いています。コード例の右上の **▶ 実行** を押すと、このページの中でそのまま実行できます。**✎ 編集** で書き換えて実行すると、下の出力がその結果に変わります。

```emojicode
🏁 🍇
  😀 🔤ようこそ！🔤❗️
🍉
```

```output
ようこそ！
```

## 読み方

- はじめての人は、[Hello World](intro/hello.md) から読み始めてください。IDE の操作は [この IDE の使い方](about/ide.md) にまとめています。
- コード例は、どれもこのサイトを作るときに実際にコンパイル・実行して、書いてあるとおりの出力になることを確かめています。
- 公式の英語のドキュメントは [Emojicode Documentation](https://www.emojicode.org/docs/) にあります。このリファレンスは、それとは別に一から書いたもので、内容は公式のものではありません。

## 対応しているバージョン

この IDE に入っている Emojicode は、公式コンパイラの [`master`](https://github.com/emojicode/emojicode/tree/master)（コミット [`4dec45b`](https://github.com/emojicode/emojicode/commit/4dec45b497e4f4dce7f5f5ae11a00d8e8e9af67c)）に、WebAssembly で動かすための修正を加えたものです。公式コンパイラで見つかっているバグは [Emojicode言語のバグ](about/known-issues.md) に、この IDE の制限は [この IDE の使い方](about/ide.md) の最後にまとめています。
