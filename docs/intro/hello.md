```emojicode

  😀 🔤Hello, World!🔤❗️
🍉
```

```output
Hello, World!
```

```keywords
hello world
```

1 行ずつ見ていきます。

## 🏁 と 🍇 🍉

`🏁` は、プログラムが動き始める場所（エントリーポイント）です。どのプログラムにも 1 つだけ書きます。

`🍇` と `🍉` は、ブロックの始まりと終わりです。ほかの言語の `{` `}` にあたります。`🏁 🍇 … 🍉` の中に書いたものが、上から順に実行されます。

```keywords
main
int main
エントリーポイント
ブロック
{}
波括弧
```

## 😀 と ❗️

`😀` は「表示する」メソッドです。Emojicode では、メソッドの呼び出しは **メソッドの絵文字を先に書き、引数（相手）を続け、最後に `❗️` で閉じる** という形になります。

```emojicode norun
😀 🔤Hello, World!🔤❗️
```

これは「`🔤Hello, World!🔤` という文字列の `😀` メソッドを呼ぶ」という意味です。ほかの言語で書くと `"Hello, World!".print()` に近い形です。

```keywords
cout
std::cout
printf
puts
print
表示
出力
メソッド呼び出し
関数呼び出し
```

## 🔤

`🔤` で挟んだものが文字列です。日本語も絵文字もそのまま書けます。

```emojicode
🏁 🍇
  😀 🔤こんにちは 👋🔤❗️
  😀 🔤2 行目🔤❗️
🍉
```

```output
こんにちは 👋
2 行目
```

`😀` は表示したあとに改行します。改行したくないときは `👄` を使います。

```keywords
endl
改行しない
```

```emojicode
🏁 🍇
  👄 🔤改行しない、🔤❗️
  😀 🔤ここで改行🔤❗️
🍉
```

```output
改行しない、ここで改行
```

## コメント

`💭` から行の終わりまではコメントです。複数行のコメントは `💭🔜` と `🔚💭` で囲みます。

```keywords
コメント
//
/* */
コメントアウト
```

```emojicode
🏁 🍇
  💭 この行は実行されない
  😀 🔤コメントの外🔤❗️
  💭🔜
    ここも
    実行されない
  🔚💭
🍉
```

```output
コメントの外
```
