# LLM 向けドキュメント

このドキュメントの内容を、大規模言語モデルが読みやすい形にまとめたものを用意しています。Emojicode について質問したり、コードを書いてもらったりする前に読ませておくと、答えの精度を上げるのに使えます。

## 読ませるもの

次の URL を読ませてください。Emojicode を書くのに必要な内容を、1 つのファイルにまとめたものです。

```copy URL
https://emojicode-ide.com/llms-full.txt
```

中身はこのドキュメントと同じで、コード例はどれも実際にコンパイル・実行して確かめたものです。

## 使い方

会話の最初に、次のプロンプトを貼り付けて使えます。

```copy チャットの最初に貼るプロンプト
Emojicode について、次の資料を読んでから答えてください。
https://emojicode-ide.com/llms-full.txt
```

URL を開けない場合は、ファイルの中身をコピーして貼り付けることもできます。

```copyfile /llms-full.txt
ファイルの中身をコピーする
```
