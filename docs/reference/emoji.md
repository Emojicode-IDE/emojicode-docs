# 絵文字早見表

Emojicode のコンパイラが「キーワード」として特別に扱う絵文字の一覧です。ここにない絵文字は、型やメソッド、変数の名前として使えます（ただし [新しめの絵文字は使えないことがあります](../about/known-issues.md#EJ021)）。

`🔢` `🔡` `🍨` のような型は、キーワードではなく、標準ライブラリ `s` で定義されている型です。主なものを最後にまとめています。標準ライブラリにある型と同じ名前の型は作れません。最後の表にない `🌳` なども使えないので、`is already defined` というエラーが出たら別の絵文字にします（[クラス](../types/classes.md)）。

|---|---|---|
| `🏁` | プログラムの始まり（エントリーポイント） | [Hello World](../intro/hello.md) |
| `🍇` `🍉` | ブロックの始まり・終わり | [Hello World](../intro/hello.md) |
| `❗️` | メソッド呼び出しの終わり | [Hello World](../intro/hello.md) |
| `❓` | 問い合わせのメソッド呼び出しの終わり（`📏 リスト❓` など） | [リストと辞書](../basics/collections.md) |
| `🤜` `🤛` | かっこ（先に計算する） | [値と変数](../basics/values.md) |
| `💭` | 1 行のコメント | [Hello World](../intro/hello.md) |
| `💭🔜` `🔚💭` | 複数行のコメント | [Hello World](../intro/hello.md) |
| `📗` | ドキュメントコメント | [パッケージとドキュメントコメント](../advanced/packages.md) |
| `📘` | パッケージのドキュメントコメント | [パッケージとドキュメントコメント](../advanced/packages.md) |
