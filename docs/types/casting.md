# 型の値とキャスト

## なんでも入る型（⚪️・🔵）

`⚪️` は「どんな値でも入る」型です。`🔵` は「どんなクラスのインスタンスでも入る」型です（値型や数は入りません）。

```emojicode
🏁 🍇
  🆕🍨🐚⚪️🍆❗️ ➡️ 🖍🆕 things
  🐻 things 42❗️
  🐻 things 🔤文字列🔤❗️
  🐻 things 👍❗️
  😀 🔡 📏 things❓❗️❗️
🍉
```

```output
3
```

```keywords
any
std::any
void*
Object
なんでも
```

## キャスト（🔲）

`⚪️` などに入っている値を、もとの型として使うには `🔲 値 型` でキャストします。結果はオプショナルで、その型でなければ値なしになります。

```emojicode
🏁 🍇
  🍿 42 🔤abc🔤 7 🍆 ➡️ things
  🔂 thing things 🍇
    ↪️ 🔲 thing 🔢 ➡️ n 🍇
      😀 🔤整数 🧲🔡 n❗️🧲🔤❗️
    🍉
    🙅↪️ 🔲 thing 🔡 ➡️ s 🍇
      😀 🔤文字列 🧲s🧲🔤❗️
    🍉
  🍉
🍉
```

```output
整数 42
文字列 abc
整数 7
```

リテラルを並べた `🍿 … 🍆` は、要素の型がばらばらだと `🍨🐚⚪️🍆` になります。

## 型を値として使う

クラスや値型、列挙型の名前は、そのまま値として使えます。型メソッド（[クラス](classes.md)）を呼ぶときの `🐇型` がそれです。

```emojicode
🐇 🌷 🍇
  🐇❗️ 🏷 ➡️ 🔡 🍇
    ↩️ 🔤チューリップ🔤
  🍉
🍉

🐇 🌹 🌷 🍇
  ✒️ 🐇❗️ 🏷 ➡️ 🔡 🍇
    ↩️ 🔤バラ🔤
  🍉
🍉

🏁 🍇
  😀 🏷🐇🌷❗️❗️
  😀 🏷🐇🌹❗️❗️
🍉
```

```output
チューリップ
バラ
```

型メソッドも、子クラスで `✒️` を使って上書きできます。

```keywords
型
type
class object
メタクラス

```

## 型の値からインスタンスを作る（⬛️）

型を変数に入れておき、`🆕⬛️ 変数❗️` で、その型のインスタンスを作れます。子クラスでも作れるように、初期化子には `🔑` をつけておきます（[クラスの応用](../advanced/classes.md)）。

```emojicode
🐇 🐾 🍇
  🔑 🆕 🍇🍉
  ❗️ 🏷 ➡️ 🔡 🍇
    ↩️ 🔤どうぶつ🔤
  🍉
🍉

🐇 🐕 🐾 🍇
  🔑 🆕 🍇 ⤴️🆕❗️ 🍉
  ✒️ ❗️ 🏷 ➡️ 🔡 🍇
    ↩️ 🔤犬🔤
  🍉
🍉

🏁 🍇
  🍿 🐇🐾 🐇🐕 🍆 ➡️ kinds
  🔂 kind kinds 🍇
    🆕⬛️ kind❗️ ➡️ animal
    😀 🏷 animal❗️❗️
  🍉
🍉
```

```output
どうぶつ
犬
```

型を値として扱うと、コンパイラが「型の値の実行時の型情報はまだ完全ではない」という警告を出しますが、この例は正しく動きます。

```keywords
ファクトリ
factory
型の値
動的生成
⬛
```

## 同じインスタンスか（😜）

`🙌` は「値が等しいか」ですが、`😜` は「まったく同じインスタンスか」を比べます。

```emojicode
🐇 🐟 🍇
  🆕 🍇🍉
🍉

🏁 🍇
  🆕🐟❗️ ➡️ a
  a ➡️ b
  🆕🐟❗️ ➡️ c
  ↪️ a 😜 b 🍇
    😀 🔤a と b は同じ🔤❗️
  🍉
  ↪️ ❎ a 😜 c❗️ 🍇
    😀 🔤a と c は別もの🔤❗️
  🍉
🍉
```

```output
a と b は同じ
a と c は別もの
```

## 型を書く手間を省く（📣・⚫）

`📣 値 型` は、リテラルの型を指定します。たとえば `🍿 🍆` だけでは空のリストの型がわからないので、`📣` で型を書きます。

```emojicode
🏁 🍇
  📣 🍿🍆 🍨🐚🔡🍆 ➡️ 🖍🆕 names
  🐻 names 🔤えもじ🔤❗️
  😀 🔡 📏 names❓❗️❗️
🍉
```

```output
1
```

```keywords
型注釈
型推論
空のリスト
auto
```

### 型を推論させる（⚫️）

コンパイラには、型を書くところに `⚫️` を書いて推論させる仕組みがあります。ただ、試した範囲（変数への代入、引数、戻り値）では、どれも `Cannot infer ⚫️.` というエラーになり、使える場面が見つかりませんでした。公式のテストや標準ライブラリにも使っている例がありません。

```emojicode error
🏁 🍇
  🖍🆕 names 🍨🐚🔡🍆
  🆕⚫️❗️ ➡️ 🖍names
🍉
```

```text
Cannot infer ⚫️.
```

```keywords
型推論
auto
⚫
```
