# クラス

## クラスを作る（🐇）

`🐇 名前 🍇 … 🍉` でクラスを作ります。名前は絵文字 1 つです。中には、インスタンス変数、初期化子（`🆕`）、メソッドを書きます。

```emojicode
🐇 🐕 🍇
  🖍🆕 name 🔡

  🆕 🍼 name 🔡 🍇🍉

  ❗️ 🗣 🍇
    😀 🔤🧲name🧲: ワン！🔤❗️
  🍉
🍉

🏁 🍇
  🆕🐕 🔤ポチ🔤❗️ ➡️ pochi
  🗣 pochi❗️
🍉
```

```output
ポチ: ワン！
```

1 つずつ見ていきます。

- `🖍🆕 name 🔡` … インスタンス変数（メンバー変数）。インスタンスごとに持つ値です。
- `🆕 🍼 name 🔡 🍇🍉` … 初期化子（コンストラクタ）。`🍼` をつけた引数は、同じ名前のインスタンス変数にそのまま入ります。
- `❗️ 🗣 🍇 … 🍉` … メソッド。中ではインスタンス変数を名前だけで使えます。
- `🆕🐕 🔤ポチ🔤❗️` … インスタンスを作る。
- `🗣 pochi❗️` … メソッドを呼ぶ。メソッドの絵文字が先、相手が後です。

```keywords
class
クラス
オブジェクト
インスタンス
new
メンバー変数
フィールド
member
constructor
コンストラクタ
初期化子
```

## 引数と戻り値

メソッドの引数は `名前 型` を並べて書きます。戻り値があるときは `➡️ 型` を書き、`↩️` で返します。

```emojicode
🐇 🧮 🍇
  🖍🆕 total 🔢

  🆕 🍇
    0 ➡️ 🖍total
  🍉

  ❗️ 📥 n 🔢 🍇
    total ⬅️➕ n
  🍉

  ❗️ 🧾 ➡️ 🔢 🍇
    ↩️ total
  🍉
🍉

🏁 🍇
  🆕🧮❗️ ➡️ calc
  📥 calc 3❗️
  📥 calc 4❗️
  😀 🔡 🧾 calc❗️❗️❗️
🍉
```

```output
7
```

初期化子の中では、インスタンス変数に `➡️ 🖍名前` で値を入れます。宣言のところで `⬅️` を使って最初の値を書いておくこともできます（`🖍🆕 total 🔢 ⬅️ 0`）。

インスタンス変数は、クラスの外からは見えません。外から値を見せたいときは、上の `🧾` のように値を返すメソッドを用意します。

```keywords
method
メソッド
メンバー関数
引数
戻り値
return
getter
ゲッター
private
カプセル化
```

## 名前のついた初期化子

`🆕 ▶️名前` で、名前のついた初期化子を作れます。作り方が何通りかあるときに便利です。

```emojicode
🐇 ⏱ 🍇
  🖍🆕 seconds 🔢

  🆕 ▶️⏲ minutes 🔢 🍇
    minutes ✖️ 60 ➡️ 🖍seconds
  🍉

  🆕 ▶️⏳ 🍼 seconds 🔢 🍇🍉

  ❗️ 🔡 ➡️ 🔡 🍇
    ↩️ 🔤🧲🔡 seconds❗️🧲 秒🔤
  🍉
🍉

🏁 🍇
  😀 🔡 🆕⏱▶️⏲ 2❗️❗️❗️
  😀 🔡 🆕⏱▶️⏳ 90❗️❗️❗️
🍉
```

```output
120 秒
90 秒
```

`❗️ 🔡 ➡️ 🔡` のように `🔡` という名前のメソッドを作っておくと、`🔡 値❗️` で文字列にできます。

```keywords
オーバーロード
複数のコンストラクタ
名前付きコンストラクタ
ファクトリ
toString
to_string
```

## 自分自身（👇）

メソッドの中で、自分自身のインスタンスは `👇` です。自分の別のメソッドを呼ぶときに使います。

```emojicode
🐇 🐈 🍇
  ❗️ 🗣 ➡️ 🔡 🍇
    ↩️ 🔤にゃー🔤
  🍉

  ❗️ 📢 🍇
    😀 🔤🧲🗣👇❗️🧲 🧲🗣👇❗️🧲🔤❗️
  🍉

  🆕 🍇🍉
🍉

🏁 🍇
  📢 🆕🐈❗️❗️
🍉
```

```output
にゃー にゃー
```

```keywords

self
自分自身
```

## 型メソッド（🐇❗️）

`🐇❗️` で作ったメソッドは、インスタンスではなく型そのものに対して呼びます。呼ぶときは `メソッド 🐇型 引数❗️` です。

```emojicode
🐇 🎲 🍇
  🐇❗️ 🔢 sides 🔢 ➡️ 🔡 🍇
    ↩️ 🔤🧲🔡 sides❗️🧲 面のさいころ🔤
  🍉
🍉

🏁 🍇
  😀 🔢🐇🎲 6❗️❗️
🍉
```

```output
6 面のさいころ
```

```keywords
static
静的メソッド
クラスメソッド
static member function
```

## 外から呼べないメソッド（🔒）

メソッドの前に `🔒` をつけると、そのクラスの中からしか呼べなくなります。

```emojicode error
🐇 🏦 🍇
  🆕 🍇🍉
  🔒❗️ 🔑 ➡️ 🔡 🍇
    ↩️ 🔤ひみつ🔤
  🍉
🍉

🏁 🍇
  😀 🔑 🆕🏦❗️❗️❗️
🍉
```

子クラスからも呼べる `🔐` など、ほかの見える範囲は [クラスの応用](../advanced/classes.md) にあります。

```keywords
private
アクセス修飾子
非公開
```

## 名前に使えない絵文字

メソッドや型の名前には、たいていの絵文字を使えますが、次のものは使えません。

- `➕` `✖️` `🔁` `↩️` のように、演算子やキーワードとして決まっている絵文字
- `🟢` `🟡` のように、比較的新しい絵文字（コンパイラが知っている絵文字の一覧が古いため。[Emojicode言語のバグ](../about/known-issues.md)）

使えないものを書くと、`Expected Identifier` というコンパイルエラーになります。

```emojicode error
🐇 🧮 🍇
  🆕 🍇🍉
  ❗️ ➕ n 🔢 🍇
  🍉
🍉

🏁 🍇
  🆕🧮❗️ ➡️ calc
🍉
```

```text
Expected Identifier
```
