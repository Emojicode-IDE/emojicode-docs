# クラス

## クラスを作る（🐇）

`🐇 名前 🍇 … 🍉` でクラスを作ります。名前は絵文字 1 つです。中には、インスタンス変数、初期化子（`🆕`）、メソッドを書きます。

```emojicode
🐇 🐕 🍇
  🖍🆕 name 🔡

  🆕 🍼 name 🔡 🍇🍉

  ❗️ 🗣 🍇
    😀 🔤🧲name🧲: ワン！🔤❗️
  🍉
🍉

🏁 🍇
  🆕🐕 🔤ポチ🔤❗️ ➡️ pochi
  🗣 pochi❗️
🍉
```

```output
ポチ: ワン！
```

1 つずつ見ていきます。

- `🖍🆕 name 🔡` … インスタンス変数（メンバー変数）。インスタンスごとに持つ値です。
- `🆕 🍼 name 🔡 🍇🍉` … 初期化子（コンストラクタ）。`🍼` をつけた引数は、同じ名前のインスタンス変数にそのまま入ります。
- `❗️ 🗣 🍇 … 🍉` … メソッド。中ではインスタンス変数を名前だけで使えます。
- `🆕🐕 🔤ポチ🔤❗️` … インスタンスを作る。
- `🗣 pochi❗️` … メソッドを呼ぶ。メソッドの絵文字が先、相手が後です。

## 引数と戻り値

メソッドの引数は `名前 型` を並べて書きます。戻り値があるときは `➡️ 型` を書き、`↩️` で返します。

```emojicode
🐇 🧮 🍇
  🖍🆕 total 🔢

  🆕 🍇
    0 ➡️ 🖍total
  🍉

  ❗️ 📥 n 🔢 🍇
    total ⬅️➕ n
  🍉

  ❗️ 🧾 ➡️ 🔢 🍇
    ↩️ total
  🍉
🍉

🏁 🍇
  🆕🧮❗️ ➡️ calc
  📥 calc 3❗️
  📥 calc 4❗️
  😀 🔡 🧾 calc❗️❗️❗️
🍉
```

```output
7
```

初期化子の中では、インスタンス変数に `➡️ 🖍名前` で値を入れます。宣言のところで `⬅️` を使って最初の値を書いておくこともできます（`🖍🆕 total 🔢 ⬅️ 0`）。

インスタンス変数は、クラスの外からは見えません。外から値を見せたいときは、上の `🧾` のように値を返すメソッドを用意します。

値を返さないメソッドから途中で戻るときは、`↩️↩️` と書きます。`↩️` だけだと、後ろに返す値が続くものとして読まれ、コンパイルエラーになります。

```emojicode
🐇 🧪 🍇
  🆕 🍇🍉

  ❗️ 🔔 n 🔢 🍇
    ↪️ n 🙌 0 🍇
      ↩️↩️
    🍉
    😀 🔤🧲🔡 n❗️🧲 は 0 ではない🔤❗️
  🍉
🍉

🏁 🍇
  🆕🧪❗️ ➡️ test
  🔔 test 0❗️
  🔔 test 1❗️
🍉
```

```output
1 は 0 ではない
```

## 名前のついた初期化子

`🆕 ▶️名前` で、名前のついた初期化子を作れます。作り方が何通りかあるときに便利です。

```emojicode
🐇 ⏱ 🍇
  🖍🆕 seconds 🔢

  🆕 ▶️⏲ minutes 🔢 🍇
    minutes ✖️ 60 ➡️ 🖍seconds
  🍉

  🆕 ▶️⏳ 🍼 seconds 🔢 🍇🍉

  ❗️ 🔡 ➡️ 🔡 🍇
    ↩️ 🔤🧲🔡 seconds❗️🧲 秒🔤
  🍉
🍉

🏁 🍇
  😀 🔡 🆕⏱▶️⏲ 2❗️❗️❗️
  😀 🔡 🆕⏱▶️⏳ 90❗️❗️❗️
🍉
```

```output
120 秒
90 秒
```

`❗️ 🔡 ➡️ 🔡` のように `🔡` という名前のメソッドを作っておくと、`🔡 値❗️` で文字列にできます。

```keywords

```

## 同じ名前で引数の違うメソッド

引数の型や数が違えば、同じ名前のメソッドや初期化子をいくつも作れます（オーバーロード）。呼ぶときに渡した値に合わせて、どれを使うかをコンパイラが決めます。

```emojicode
🐇 🖨 🍇
  🆕 🍇🍉

  🆕 n 🔢 🍇
    😀 🔤数から作った🔤❗️
  🍉

  🆕 s 🔡 🍇
    😀 🔤文字列から作った🔤❗️
  🍉

  ❗️ 📄 n 🔢 🍇
    😀 🔤数: 🧲🔡 n❗️🧲🔤❗️
  🍉

  ❗️ 📄 s 🔡 🍇
    😀 🔤文字列: 🧲s🧲🔤❗️
  🍉

  ❗️ 📄 s 🔡 n 🔢 🍇
    😀 🔤文字列と数: 🧲s🧲 🧲🔡 n❗️🧲🔤❗️
  🍉
🍉

🏁 🍇
  🆕🖨 1❗️
  🆕🖨 🔤x🔤❗️
  🆕🖨❗️ ➡️ p
  📄 p 3❗️
  📄 p 🔤x🔤❗️
  📄 p 🔤x🔤 3❗️
🍉
```

```output
数から作った
文字列から作った
数: 3
文字列: x
文字列と数: x 3
```

区別に使われるのは、名前、`❗️` か `❓` か、引数の数、引数の型です。戻り値の型だけが違うものは区別されません。引数の型までまったく同じものを 2 つ書いてもコンパイルエラーにはならず、呼ぶと後に書いたほうが黙って使われます（[EJ020](../about/known-issues.md#EJ020)）。

### どれが呼ばれるか

コンパイラは、まず名前と引数の数が合い、渡した値をすべての引数に入れられるものを集めます。それが 1 つならそれを呼びます。2 つ以上あるときは、引数の型がより狭いものを選びます（ただし、下で説明するメソッドだけのジェネリクスの決まりが先に効きます）。`🐕` が `🐾` を継承しているなら `🐕` のほうが狭くなります。`⚪️` はどんな型よりも広い型ですが、引数の型を `⚪️` にしたメソッドは、公式コンパイラでは書いただけで内部のチェックで止まります（[EJ032](../about/known-issues.md#EJ032)）。

```emojicode
🐇 🐾 🍇
  🆕 🍇🍉
🍉

🐇 🐕 🐾 🍇
🍉

🐇 🔎 🍇
  🆕 🍇🍉

  ❗️ 📄 a 🐾 🍇
    😀 🔤動物🔤❗️
  🍉

  ❗️ 📄 a 🐕 🍇
    😀 🔤犬🔤❗️
  🍉
🍉

🏁 🍇
  🆕🔎❗️ ➡️ f
  📄 f 🆕🐾❗️❗️
  📄 f 🆕🐕❗️❗️
  🖍🆕 pet 🐾
  🆕🐕❗️ ➡️ 🖍pet
  📄 f pet❗️
🍉
```

```output
動物
犬
動物
```

最後の `pet` の中身は `🐕` ですが、選ぶのはコンパイルするときなので、変数の型 `🐾` で決まります。

引数が 2 つ以上あるときは、候補を 2 つずつ比べ、引数ごとに「こちらの型が相手の型に入るか」を数えます。入るものが引数の半分より多いほうが、狭いとみなされます。ただし、候補の中に [メソッドだけのジェネリクス](../advanced/classes.md) を使ったものとそうでないものが混ざっていて、使っていないものが 1 つだけなら、引数の型の狭さを比べる前に、それが選ばれます。引数の型が広いほうでも選ばれます。

どちらも狭いとはいえないときは、`Ambiguous call to` というコンパイルエラーになります。次の例では、`🔢` は `🍬🔢` に入りますが逆は入らないので、2 つの候補がそれぞれ 1 つずつの引数でしか狭くなく、決められません。

```emojicode error
🐇 🖨 🍇
  🆕 🍇🍉

  ❗️ 📄 a 🔢 b 🍬🔢 🍇
    😀 🔤1 つめ🔤❗️
  🍉

  ❗️ 📄 a 🍬🔢 b 🔢 🍇
    😀 🔤2 つめ🔤❗️
  🍉
🍉

🏁 🍇
  🆕🖨❗️ ➡️ p
  📄 p 1 2❗️
🍉
```

```text
Ambiguous call to 📄.
```

どれにも合わないときのエラーは `has no suitable` で、候補ごとに何番めの引数が合わなかったかが添えられます。

## 自分自身（👇）

メソッドの中で、自分自身のインスタンスは `👇` です。自分の別のメソッドを呼ぶときに使います。

```emojicode
🐇 🐈 🍇
  ❗️ 🗣 ➡️ 🔡 🍇
    ↩️ 🔤にゃー🔤
  🍉

  ❗️ 📢 🍇
    😀 🔤🧲🗣👇❗️🧲 🧲🗣👇❗️🧲🔤❗️
  🍉

  🆕 🍇🍉
🍉

🏁 🍇
  📢 🆕🐈❗️❗️
🍉
```

```output
にゃー にゃー
```

## 型メソッド（🐇❗️）

`🐇❗️` で作ったメソッドは、インスタンスではなく型そのものに対して呼びます。呼ぶときは `メソッド 🐇型 引数❗️` です。

```emojicode
🐇 🎲 🍇
  🐇❗️ 🔢 sides 🔢 ➡️ 🔡 🍇
    ↩️ 🔤🧲🔡 sides❗️🧲 面のさいころ🔤
  🍉
🍉

🏁 🍇
  😀 🔢🐇🎲 6❗️❗️
🍉
```

```output
6 面のさいころ
```

## 外から呼べないメソッド（🔒）

メソッドの前に `🔒` をつけると、そのクラスの中からしか呼べなくなります。

```emojicode error
🐇 🏦 🍇
  🆕 🍇🍉
  🔒❗️ 🔑 ➡️ 🔡 🍇
    ↩️ 🔤ひみつ🔤
  🍉
🍉

🏁 🍇
  😀 🔑 🆕🏦❗️❗️❗️
🍉
```

子クラスからも呼べる `🔐` など、ほかの見える範囲は [クラスの応用](../advanced/classes.md) にあります。

## 名前に使えない絵文字

メソッドや型の名前には、たいていの絵文字を使えますが、次のものは使えません。

- `➕` `✖️` `🔁` `↩️` のように、演算子やキーワードとして決まっている絵文字
- `🟢` `🟡` のように、比較的新しい絵文字（コンパイラが知っている絵文字の一覧が古いため。[EJ021](../about/known-issues.md#EJ021)）

使えないものを書くと、`Expected Identifier` というコンパイルエラーになります。

```emojicode error
🐇 🧮 🍇
  🆕 🍇🍉
  ❗️ ➕ n 🔢 🍇
  🍉
🍉

🏁 🍇
  🆕🧮❗️ ➡️ calc
🍉
```

```text
Expected Identifier
```

また、標準ライブラリ `s` にある型と同じ名前の型は作れません。`🔢` や `🍨` のほか、`🌳` のように [絵文字早見表](../reference/emoji.md) に載っていない型もあります。`is already defined` というエラーが出たら、別の絵文字にします。

```emojicode error
🐇 🌳 🍇
  🆕 🍇🍉
🍉

🏁 🍇
  🆕🌳❗️ ➡️ tree
🍉
```

```text
is already defined
```

## 2 つ以上の絵文字でできた名前（🔸）

型やメソッドの名前は、絵文字 1 つです。2 つ以上の絵文字を 1 つの名前にしたいときは、間を `🔸` でつなぎます。呼ぶときも同じように書きます。

```emojicode
🐇 🧮 🍇
  🆕 🍇🍉

  ❗️ 🔝🔸🔢 ➡️ 🔢 🍇
    ↩️ 1
  🍉
🍉

🏁 🍇
  😀 🔡 🔝🔸🔢 🆕🧮❗️❗️❗️❗️
🍉
```

```output
1
```

`🔸` を書かずに `🔝🔢` と並べると、名前は `🔝` だけで、その後ろに余分な `🔢` があると読まれます。エラーは `Expected BlockBegin` のようになり、名前のせいだとはわかりにくいので注意してください。

```emojicode error
🐇 🧮 🍇
  🆕 🍇🍉

  ❗️ 🔝🔢 ➡️ 🔢 🍇
    ↩️ 1
  🍉
🍉

🏁 🍇
  😀 🔡 🔝🔢 🆕🧮❗️❗️❗️❗️
🍉
```

```text
Expected BlockBegin
```
