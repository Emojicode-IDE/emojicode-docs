# クロージャ

## 関数を値として扱う

`🍇 引数 ➡️ 戻り値の型 … 🍉` で、名前のない関数（**クロージャ**）を作れます。変数に入れたり、引数として渡したりできます。呼ぶときは `⁉️ クロージャ 引数❗️` です。

```emojicode
🏁 🍇
  🍇 x 🔢 ➡️ 🔢
    ↩️ x ✖️ 2
  🍉 ➡️ double

  😀 🔡 ⁉️ double 21❗️❗️❗️
🍉
```

```output
42
```

クロージャの型は `🍇引数の型 ➡️ 戻り値の型🍉` と書きます。上の `double` の型は `🍇🔢➡️🔢🍉` です。

## 引数として渡す

クロージャを受け取るメソッドを作ると、「何をするか」を呼ぶ側が決められます。

```emojicode
🐇 🧮 🍇
  🐇❗️ 🎡 f 🍇🔢➡️🔢🍉 times 🔢 start 🔢 ➡️ 🔢 🍇
    start ➡️ 🖍🆕 value
    🔂 i 🆕⏩ 0 times❗️ 🍇
      ⁉️ f value❗️ ➡️ 🖍value
    🍉
    ↩️ value
  🍉
🍉

🏁 🍇
  😀 🔡 🎡🐇🧮 🍇 x 🔢 ➡️ 🔢 ↩️ x ✖️ 2 🍉 10 1❗️❗️❗️
  😀 🔡 🎡🐇🧮 🍇 x 🔢 ➡️ 🔢 ↩️ x ➕ 3 🍉 4 0❗️❗️❗️
🍉
```

```output
1024
12
```

リストの並べ替え（`🦁`）や変換（`🐰`）も、この形でクロージャを受け取ります（[リストと辞書](../basics/collections.md)）。

```keywords

```

## 外の変数を使う（キャプチャ）

クロージャの中からは、作った場所の変数を使えます。

```emojicode
🏁 🍇
  🔤こんにちは🔤 ➡️ greeting
  🍇 name 🔡 ➡️ 🔡
    ↩️ 🔤🧲greeting🧲、🧲name🧲！🔤
  🍉 ➡️ greet

  😀 ⁉️ greet 🔤えもじ🔤❗️❗️
🍉
```

```output
こんにちは、えもじ！
```

## 外に持ち出すクロージャ（🎍🥡）

クロージャを戻り値にしたり、インスタンス変数にしまったりして、作った場所より長く使うときは、`🍇🎍🥡` のように `🎍🥡` をつけます。

```emojicode
🐇 🏭 🍇
  🐇❗️ 🎛 factor 🔢 ➡️ 🍇🔢➡️🔢🍉 🍇
    ↩️ 🍇🎍🥡 x 🔢 ➡️ 🔢
      ↩️ x ✖️ factor
    🍉
  🍉
🍉

🏁 🍇
  🎛🐇🏭 3❗️ ➡️ triple
  😀 🔡 ⁉️ triple 5❗️❗️❗️
🍉
```

```output
15
```

`🎍🥡` をつけ忘れて外に持ち出そうとすると、コンパイルエラーになります。

```emojicode error
🐇 🏭 🍇
  🐇❗️ 🎛 factor 🔢 ➡️ 🍇🔢➡️🔢🍉 🍇
    ↩️ 🍇 x 🔢 ➡️ 🔢
      ↩️ x ✖️ factor
    🍉
  🍉
🍉

🏁 🍇
  🎛🐇🏭 3❗️ ➡️ triple
🍉
```
