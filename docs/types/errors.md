# エラー処理

## エラーを投げるかもしれないメソッド（🚧）

戻り値の後ろに `🚧 エラーの型` と書いたメソッドは、エラーを投げることがあります。エラーの型には、標準ライブラリの `🚧`（メッセージを持つエラー）が使えます。エラーは `🚨` で投げます。

```emojicode
🐇 🧮 🍇
  🐇❗️ 🍰 a 🔢 b 🔢 ➡️ 🔢 🚧🚧 🍇
    ↪️ b 🙌 0 🍇
      🚨🆕🚧 🔤0 で割ろうとした🔤❗️
    🍉
    ↩️ a ➗ b
  🍉
🍉

🏁 🍇
  🆗 result 🍰🐇🧮 10 2❗️ 🍇
    😀 🔡 result❗️❗️
  🍉
  🙅 error 🍇
    😀 💬 error❗️❗️
  🍉

  🆗 result 🍰🐇🧮 1 0❗️ 🍇
    😀 🔡 result❗️❗️
  🍉
  🙅 error 🍇
    😀 🔤エラー: 🧲💬 error❗️🧲🔤❗️
  🍉
🍉
```

```output
5
エラー: 0 で割ろうとした
```

`🚧🚧` は「`🚧` 型のエラーを投げることがある」という意味です（1 つ目の `🚧` が目印、2 つ目がエラーの型）。

## 受け止める（🆗 / 🙅）

`🆗 名前 呼び出し 🍇 … 🍉 🙅 エラーの名前 🍇 … 🍉` で、成功したときと、エラーになったときの処理を分けます。上の例のように、エラーのメッセージは `💬 エラー❗️` で取り出せます。

エラーを投げるかもしれないメソッドを、受け止めずにそのまま呼ぶことはできません。

```emojicode error
🐇 🧮 🍇
  🐇❗️ 🍰 a 🔢 b 🔢 ➡️ 🔢 🚧🚧 🍇
    ↩️ a ➗ b
  🍉
🍉

🏁 🍇
  😀 🔡 🍰🐇🧮 10 2❗️❗️❗️
🍉
```

## 呼び出し元に任せる（🔺）

エラーを投げるメソッドの中では、`🔺` をつけて呼ぶと、エラーをそのまま呼び出し元に投げ直せます。

```emojicode
🐇 🧮 🍇
  🐇❗️ 🍰 a 🔢 b 🔢 ➡️ 🔢 🚧🚧 🍇
    ↪️ b 🙌 0 🍇
      🚨🆕🚧 🔤0 で割ろうとした🔤❗️
    🍉
    ↩️ a ➗ b
  🍉

  🐇❗️ 📊 total 🔢 count 🔢 ➡️ 🔡 🚧🚧 🍇
    🔺🍰🐇🧮 total count❗️ ➡️ average
    ↩️ 🔤平均 🧲🔡 average❗️🧲🔤
  🍉
🍉

🏁 🍇
  🆗 text 📊🐇🧮 0 0❗️ 🍇
    😀 text❗️
  🍉
  🙅 error 🍇
    😀 💬 error❗️❗️
  🍉
🍉
```

```output
0 で割ろうとした
```

## 必ず成功するとわかっているとき（🍺）

`🍺` をつけて呼ぶと、エラーを受け止めずに結果だけを取り出します。**エラーになったら、プログラムはそこで止まります。**

```emojicode
🐇 🧮 🍇
  🐇❗️ 🍰 a 🔢 b 🔢 ➡️ 🔢 🚧🚧 🍇
    ↪️ b 🙌 0 🍇
      🚨🆕🚧 🔤0 で割ろうとした🔤❗️
    🍉
    ↩️ a ➗ b
  🍉
🍉

🏁 🍇
  😀 🔡 🍺🍰🐇🧮 9 3❗️❗️❗️
🍉
```

```output
3
```
