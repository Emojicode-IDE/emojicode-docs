# ジェネリクス

## 型を後から決める（🐚）

型の名前の後ろに `🐚名前 制約🍆` と書くと、中で使う型を、使うときに決められるようになります。

```emojicode
🐇 🎁 🐚T ⚪️🍆 🍇
  🖍🆕 content T

  🆕 🍼 content T 🍇🍉

  ❗️ 📤 ➡️ T 🍇
    ↩️ content
  🍉
🍉

🏁 🍇
  🆕🎁🐚🔡🍆 🔤ひみつ🔤❗️ ➡️ textBox
  🆕🎁🐚🔢🍆 42❗️ ➡️ numberBox
  😀 📤 textBox❗️❗️
  😀 🔡 📤 numberBox❗️ ➕ 1❗️❗️
🍉
```

```output
ひみつ
43
```

`🎁🐚🔡🍆` は「文字列を入れる箱」、`🎁🐚🔢🍆` は「整数を入れる箱」です。`📤` の戻り値の型も、それぞれ `🔡` と `🔢` になります。リスト（`🍨🐚🔢🍆`）や辞書も、この仕組みで作られています。

`⚪️` は制約で、「どんな型でもよい」という意味です。

```keywords
総称型

型パラメータ
```

## 制約をつける

制約にプロトコルを書くと、そのプロトコルを守っている型だけを受け取れます。代わりに、中でそのプロトコルのメソッドを呼べます。

```emojicode
🐊 🏷 🍇
  ❗️ 🔡 ➡️ 🔡
🍉

🕊 🍎 🍇
  🐊 🏷
  🆕 🍇🍉
  ❗️ 🔡 ➡️ 🔡 🍇
    ↩️ 🔤りんご🔤
  🍉
🍉

🐇 📦🐚T 🏷🍆 🍇
  🖍🆕 items 🍨🐚T🍆

  🆕 🍇
    🆕🍨🐚T🍆❗️ ➡️ 🖍items
  🍉

  ❗️ 📥 item T 🍇
    🐻 items item❗️
  🍉

  ❗️ 📋 🍇
    🔂 item items 🍇
      😀 🔤- 🧲🔡 item❗️🧲🔤❗️
    🍉
  🍉
🍉

🏁 🍇
  🆕📦🐚🍎🍆❗️ ➡️ box
  📥 box 🆕🍎❗️❗️
  📥 box 🆕🍎❗️❗️
  📋 box❗️
🍉
```

```output
- りんご
- りんご
```

メソッドだけで型を受け取る書き方は [クラスの応用](../advanced/classes.md) にあります。

## ジェネリックなクラスを継承する

ジェネリックなクラスを親にするときは、親の名前の後ろに型引数も書きます。具体的な型を書けば、その型に決めた子クラスになります。子クラスにも `🐚…🍆` をつけて、その名前を親に渡せば、子クラスもジェネリックなままです。

```emojicode
🐇 🎁 🐚T ⚪️🍆 🍇
  🖍🆕 content T

  🆕 🍼 content T 🍇🍉

  ❗️ 📤 ➡️ T 🍇
    ↩️ content
  🍉
🍉

🐇 🧮 🎁🐚🔢🍆 🍇
  ❗️ ⏫ ➡️ 🔢 🍇
    ↩️ content ✖️ 2
  🍉
🍉

🐇 🎀 🐚T ⚪️🍆 🎁🐚T🍆 🍇
  ❗️ 🎉 ➡️ 🍨🐚T🍆 🍇
    ↩️ 🍿 content content 🍆
  🍉
🍉

🏁 🍇
  🆕🧮 21❗️ ➡️ n
  😀 🔡 ⏫ n❗️❗️❗️
  🆕🎀🐚🔡🍆 🔤やあ🔤❗️ ➡️ r
  😀 🆕🔡 🎉 r❗️ 🔤 🔤❗️❗️
  🖍🆕 box 🎁🐚🔡🍆
  r ➡️ 🖍box
  😀 📤 box❗️❗️
🍉
```

```output
42
やあ やあ
やあ
```

`🧮` は「`🔢` を入れる `🎁`」を継承したクラスなので、`content` は `🔢` として使えます。`🎀🐚🔡🍆` は `🎁🐚🔡🍆` の子なので、`🎁🐚🔡🍆` の変数に入れられます。どちらも初期化子を書いていないので、親の `🆕` で作っています。

子クラスで初期化子を作るときは、ふつうのクラスと同じく、`⤴️🆕` で親の初期化子を呼びます（[継承](inheritance.md)）。`🏷` はジェネリックなままの子、`🎲` は型引数を `🔢` に決めた子です。

```emojicode
🐇 🎁 🐚T ⚪️🍆 🍇
  🖍🆕 content T

  🆕 🍼 content T 🍇🍉

  ❗️ 📤 ➡️ T 🍇
    ↩️ content
  🍉
🍉

🐇 🏷 🐚T ⚪️🍆 🎁🐚T🍆 🍇
  🖍🆕 label 🔡

  🆕 🍼 label 🔡 value T 🍇
    ⤴️🆕 value❗️
  🍉

  ❗️ 📛 ➡️ 🔡 🍇
    ↩️ label
  🍉
🍉

🐇 🎲 🎁🐚🔢🍆 🍇
  🆕 🍇
    ⤴️🆕 6❗️
  🍉
🍉

🏁 🍇
  🆕🏷🐚🔢🍆 🔤りんご🔤 3❗️ ➡️ t
  😀 🔤🧲📛 t❗️🧲: 🧲🔡 📤 t❗️❗️🧲🔤❗️
  🆕🏷🐚🔡🍆 🔤色🔤 🔤赤🔤❗️ ➡️ c
  😀 🔤🧲📛 c❗️🧲: 🧲📤 c❗️🧲🔤❗️
  😀 🔡 📤 🆕🎲❗️❗️❗️❗️
🍉
```

```output
りんご: 3
色: 赤
6
```

子クラスの型引数を親に渡すとき、その制約は親の制約を満たさなければなりません。親が `🐚T 🔢🍆` なのに子が `🐚T ⚪️🍆` のままだと、`is not compatible to constraint` というエラーになります。

公式コンパイラでは、ジェネリックなクラスを継承した子クラスの初期化子で `⤴️🆕` を呼ぶと、親の初期化子に型引数が渡らず、正しく動かないバグがあります。この IDE では直しています（[修正済みのバグ](../about/patched.md)）。

```keywords
ジェネリッククラスの継承
テンプレートクラスの継承
generic subclass
class template inheritance
型引数を渡す
```

## ジェネリックなプロトコル

プロトコルにも `🐊 名前🐚名前 制約🍆` で型引数をつけられます。守る側は `🐊 🗃🐚🔢 🔡🍆` のように型引数を決めて書き、メソッドはその型で作ります。

```emojicode
🐊 🗃 🐚K ⚪️ V ⚪️🍆 🍇
  ❗️ 🔍 key K ➡️ 🍬V
🍉

🐇 📒 🍇
  🖍🆕 names 🍨🐚🔡🍆

  🆕 🍇
    🍿 🔤ゼロ🔤 🔤いち🔤 🔤に🔤 🍆 ➡️ 🖍names
  🍉

  🐊 🗃🐚🔢 🔡🍆

  ❗️ 🔍 key 🔢 ➡️ 🍬🔡 🍇
    ↪️ key ◀️ 0 👐 key ▶️🙌 📏 names❓ 🍇
      ↩️ 🤷‍♀️
    🍉
    ↩️ 🐽 names key❗️
  🍉
🍉

🏁 🍇
  🖍🆕 store 🗃🐚🔢 🔡🍆
  🆕📒❗️ ➡️ 🖍store
  ↪️ 🔍 store 1❗️ ➡️ name 🍇
    😀 name❗️
  🍉
  ↪️ 🔍 store 5❗️ 🙌 🤷‍♀️ 🍇
    😀 🔤ない🔤❗️
  🍉
🍉
```

```output
いち
ない
```

`📒` は「`🔢` で引いて `🔡` が返る `🗃`」です。`🗃🐚🔢 🔡🍆` の変数には、同じ型引数で `🗃` を守っている型の値を入れられます。ジェネリックなクラスが、自分の型引数を使って `🐊 🗃🐚🔡 T🍆` のように守ることもできます。

プロトコルそのものの説明は [プロトコル](protocols.md) にあります。

```keywords
ジェネリックプロトコル
generic protocol
generic interface
ジェネリックインターフェース
型引数つきのプロトコル
```
