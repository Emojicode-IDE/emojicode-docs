# ジェネリクス

## 型を後から決める（🐚）

型の名前の後ろに `🐚名前 制約🍆` と書くと、中で使う型を、使うときに決められるようになります。

```emojicode
🐇 🎁 🐚T ⚪️🍆 🍇
  🖍🆕 content T

  🆕 🍼 content T 🍇🍉

  ❗️ 📤 ➡️ T 🍇
    ↩️ content
  🍉
🍉

🏁 🍇
  🆕🎁🐚🔡🍆 🔤ひみつ🔤❗️ ➡️ textBox
  🆕🎁🐚🔢🍆 42❗️ ➡️ numberBox
  😀 📤 textBox❗️❗️
  😀 🔡 📤 numberBox❗️ ➕ 1❗️❗️
🍉
```

```output
ひみつ
43
```

`🎁🐚🔡🍆` は「文字列を入れる箱」、`🎁🐚🔢🍆` は「整数を入れる箱」です。`📤` の戻り値の型も、それぞれ `🔡` と `🔢` になります。リスト（`🍨🐚🔢🍆`）や辞書も、この仕組みで作られています。

`⚪️` は制約で、「どんな型でもよい」という意味です。

```keywords
template
テンプレート
typename
generics
ジェネリクス
総称型
型引数
型パラメータ
```

## 制約をつける

制約にプロトコルを書くと、そのプロトコルを守っている型だけを受け取れます。代わりに、中でそのプロトコルのメソッドを呼べます。

```emojicode
🐊 🏷 🍇
  ❗️ 🔡 ➡️ 🔡
🍉

🕊 🍎 🍇
  🐊 🏷
  🆕 🍇🍉
  ❗️ 🔡 ➡️ 🔡 🍇
    ↩️ 🔤りんご🔤
  🍉
🍉

🐇 📦🐚T 🏷🍆 🍇
  🖍🆕 items 🍨🐚T🍆

  🆕 🍇
    🆕🍨🐚T🍆❗️ ➡️ 🖍items
  🍉

  ❗️ 📥 item T 🍇
    🐻 items item❗️
  🍉

  ❗️ 📋 🍇
    🔂 item items 🍇
      😀 🔤- 🧲🔡 item❗️🧲🔤❗️
    🍉
  🍉
🍉

🏁 🍇
  🆕📦🐚🍎🍆❗️ ➡️ box
  📥 box 🆕🍎❗️❗️
  📥 box 🆕🍎❗️❗️
  📋 box❗️
🍉
```

```output
- りんご
- りんご
```

メソッドだけで型を受け取る書き方は [クラスの応用](../advanced/classes.md) にあります。

```keywords
制約
concept
requires
where
境界
```
