# 継承

## 親クラスを決める

クラス名の後ろに、もう 1 つクラス名を書くと、そのクラスを **継承** します。親クラスのインスタンス変数とメソッドを、そのまま使えます。

```emojicode
🐇 🐾 🍇
  🖍🆕 name 🔡
  🆕 🍼 name 🔡 🍇🍉

  ❗️ 🗣 🍇
    😀 🔤🧲name🧲 は鳴いた🔤❗️
  🍉

  ❗️ 🚶 🍇
    😀 🔤🧲name🧲 は歩いた🔤❗️
  🍉
🍉

🐇 🐕 🐾 🍇
  ✒️ ❗️ 🗣 🍇
    😀 🔤🧲name🧲: ワン！🔤❗️
  🍉
🍉

🏁 🍇
  🆕🐕 🔤ポチ🔤❗️ ➡️ pochi
  🗣 pochi❗️
  🚶 pochi❗️
🍉
```

```output
ポチ: ワン！
ポチ は歩いた
```

`🐇 🐕 🐾` は「`🐾` を継承した `🐕`」です。`🐕` には `🆕` を書いていないので、親の `🆕` がそのまま使えます。

```keywords
継承
extends
inheritance
親クラス
基底クラス
派生クラス
サブクラス
subclass
```

## 上書きする（✒️）

親と同じメソッドを子で作り直すときは、前に `✒️` をつけます。つけ忘れるとコンパイルエラーになるので、うっかり上書きしてしまうことがありません。

```emojicode error
🐇 🐾 🍇
  🆕 🍇🍉
  ❗️ 🗣 🍇
    😀 🔤…🔤❗️
  🍉
🍉

🐇 🐕 🐾 🍇
  ❗️ 🗣 🍇
    😀 🔤ワン🔤❗️
  🍉
🍉

🏁 🍇
  🗣 🆕🐕❗️❗️
🍉
```

```keywords
override
virtual
オーバーライド
上書き
```

## 親のメソッドを呼ぶ（⤴️）

上書きしたメソッドの中から親のメソッドを呼ぶときは、`⤴️` を使います。

```emojicode
🐇 🐾 🍇
  🆕 🍇🍉
  ❗️ 🗣 🍇
    😀 🔤（鳴き声）🔤❗️
  🍉
🍉

🐇 🐕 🐾 🍇
  ✒️ ❗️ 🗣 🍇
    ⤴️🗣❗️
    😀 🔤ワン！🔤❗️
  🍉
🍉

🏁 🍇
  🗣 🆕🐕❗️❗️
🍉
```

```output
（鳴き声）
ワン！
```

子クラスで初期化子を作るときは、その中で `⤴️🆕 …❗️` と書いて、親の初期化子を呼びます。

```emojicode
🐇 🐾 🍇
  🖍🆕 name 🔡
  🆕 🍼 name 🔡 🍇🍉
  ❗️ 🏷 ➡️ 🔡 🍇
    ↩️ name
  🍉
🍉

🐇 🐈 🐾 🍇
  🖍🆕 lives 🔢
  🆕 name 🔡 🍇
    9 ➡️ 🖍lives
    ⤴️🆕 name❗️
  🍉
  ❗️ 📋 🍇
    😀 🔤🧲🏷👇❗️🧲 は命が 🧲🔡 lives❗️🧲 つ🔤❗️
  🍉
🍉

🏁 🍇
  📋 🆕🐈 🔤タマ🔤❗️❗️
🍉
```

```output
タマ は命が 9 つ
```

子クラスのインスタンス変数に値を入れてから、親の初期化子を呼びます。

```keywords
super
親のメソッド
基底クラスの呼び出し
```

## 親の型として扱う

子クラスのインスタンスは、親クラスの型の変数やリストに入れられます。メソッドを呼ぶと、それぞれの子クラスのメソッドが実行されます。

```emojicode
🐇 🐾 🍇
  🆕 🍇🍉
  ❗️ 🗣 ➡️ 🔡 🍇
    ↩️ 🔤…🔤
  🍉
🍉

🐇 🐕 🐾 🍇
  ✒️ ❗️ 🗣 ➡️ 🔡 🍇
    ↩️ 🔤ワン🔤
  🍉
🍉

🐇 🐈 🐾 🍇
  ✒️ ❗️ 🗣 ➡️ 🔡 🍇
    ↩️ 🔤ニャー🔤
  🍉
🍉

🏁 🍇
  🆕🍨🐚🐾🍆❗️ ➡️ 🖍🆕 animals
  🐻 animals 🆕🐕❗️❗️
  🐻 animals 🆕🐈❗️❗️
  🔂 a animals 🍇
    😀 🗣 a❗️❗️
  🍉
🍉
```

```output
ワン
ニャー
```

```keywords
ポリモーフィズム
多態性
polymorphism
仮想関数
動的ディスパッチ
```
