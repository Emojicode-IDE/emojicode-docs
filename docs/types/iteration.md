# 自作の型を 🔂 で回す

`🔂` で回せるのは、プロトコル `🔂` を守っている型です。リストや範囲（`⏩`）もそうなっています。自分の型でも、このプロトコルを守れば `🔂` で回せます。

| プロトコル | 用意するメソッド |
|---|---|
| `🔂🐚要素の型🍆` | `❗️ 🍡 ➡️ 🍡🐚要素の型🍆`：イテレータを返す |
| `🍡🐚要素の型🍆` | `❓ 🔽 ➡️ 👌`：まだ次があるか / `❗️ 🔽 ➡️ 要素の型`：次の要素 |

```emojicode
🐇 🎢 🍇
  🐊 🍡🐚🔢🍆
  🖍🆕 current 🔢
  🖍🆕 last 🔢

  🆕 🍼 current 🔢 🍼 last 🔢 🍇🍉

  ❓ 🔽 ➡️ 👌 🍇
    ↩️ current ◀️🙌 last
  🍉

  ❗️ 🔽 ➡️ 🔢 🍇
    current ➡️ value
    current ⬅️✖️ 2
    ↩️ value
  🍉
🍉

🐇 📈 🍇
  🐊 🔂🐚🔢🍆
  🖍🆕 limit 🔢
  🆕 🍼 limit 🔢 🍇🍉

  ❗️ 🍡 ➡️ 🍡🐚🔢🍆 🍇
    ↩️ 🆕🎢 1 limit❗️
  🍉
🍉

🏁 🍇
  🔂 n 🆕📈 100❗️ 🍇
    👄 🔤🧲🔡 n❗️🧲 🔤❗️
  🍉
  😀 🔤🔤❗️
🍉
```

```output
1 2 4 8 16 32 64 
```

`📈` は「100 までの 2 のべき乗」を表す型で、`🎢` がそれを 1 つずつ取り出すイテレータです。型の名前は絵文字 1 つなので、`🔢🔁` のように 2 つ並べることはできません。
