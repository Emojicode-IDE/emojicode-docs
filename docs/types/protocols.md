# プロトコル

## 約束だけを決める（🐊）

`🐊` で作る **プロトコル** は、「このメソッドを持っていること」という約束だけを決めた型です。中身は書きません。

クラスや値型の中に `🐊 プロトコル名` と書くと、その約束を守る（メソッドを全部用意する）ことになります。

```emojicode
🐊 🔊 🍇
  ❗️ 🗣 ➡️ 🔡
🍉

🐇 🐕 🍇
  🐊 🔊
  🆕 🍇🍉
  ❗️ 🗣 ➡️ 🔡 🍇
    ↩️ 🔤ワン🔤
  🍉
🍉

🕊 🔔 🍇
  🐊 🔊
  🆕 🍇🍉
  ❗️ 🗣 ➡️ 🔡 🍇
    ↩️ 🔤カーン🔤
  🍉
🍉

🏁 🍇
  🆕🍨🐚🔊🍆❗️ ➡️ 🖍🆕 things
  🐻 things 🆕🐕❗️❗️
  🐻 things 🆕🔔❗️❗️
  🔂 t things 🍇
    😀 🗣 t❗️❗️
  🍉
🍉
```

```output
ワン
カーン
```

`🐕` はクラス、`🔔` は値型ですが、どちらも `🔊` の約束を守っているので、同じ `🍨🐚🔊🍆` に入れられます。

約束のメソッドを用意し忘れると、コンパイルエラーになります。

```emojicode error
🐊 🔊 🍇
  ❗️ 🗣 ➡️ 🔡
🍉

🐇 🐕 🍇
  🐊 🔊
  🆕 🍇🍉
🍉

🏁 🍇
  🆕🐕❗️ ➡️ dog
🍉
```

標準ライブラリのプロトコルを守って、自分の型を `🔂` で回せるようにする例は [自作の型を 🔂 で回す](iteration.md) にあります。

```keywords

インターフェース
protocol
プロトコル
抽象クラス
純粋仮想関数
pure virtual

concept
```

## 等しいかを比べられる型（😛）

標準ライブラリの `😛🐚T⚪️🍆` は、「`🙌` で T と等しいかを比べられる」という約束のプロトコルです。`🙌 other T ➡️ 👌` の 1 つだけを決めています。`🔢` `💯` `🔡` `👌` `💧` `📇` は、どれも `😛` に自分の型を渡して守っています。

リストの `🐦`（等しい要素があるか）と、リストどうしの `🙌` は、渡す値の型（`🙌` なら相手のリストの要素の型）が `😛🐚要素の型🍆` を守っているときだけ使えます。ふつうは要素の型そのものが `😛🐚自分の型🍆` を守っているので、同じ型の値を渡せば使えます。自分で作った型も、`🐊 😛🐚自分の型🍆` と書いて `🙌` を用意すれば、これらに使えます。

```emojicode
🕊 🧺 🍇
  🐊 😛🐚🧺🍆
  🖍🆕 apples 🔢
  🖍🆕 oranges 🔢

  🆕 🍼 apples 🔢 🍼 oranges 🔢 🍇🍉

  ❗️ 🍎 ➡️ 🔢 🍇
    ↩️ apples
  🍉

  ❗️ 🍊 ➡️ 🔢 🍇
    ↩️ oranges
  🍉

  🙌 other 🧺 ➡️ 👌 🍇
    ↩️ apples 🙌 🍎 other❗️ 🤝 oranges 🙌 🍊 other❗️
  🍉
🍉

🏁 🍇
  🆕🧺 1 2❗️ ➡️ a
  🆕🧺 1 2❗️ ➡️ b
  ↪️ a 🙌 b 🍇
    😀 🔤同じ🔤❗️
  🍉
  🍿 🆕🧺 0 3❗️ a 🍆 ➡️ baskets
  ↪️ 🐦 baskets 🆕🧺 1 2❗️❓ 🍇
    😀 🔤見つかった🔤❗️
  🍉
  ↪️ baskets 🙌 🍿 🆕🧺 0 3❗️ b 🍆 🍇
    😀 🔤リストも同じ🔤❗️
  🍉
🍉
```

```output
同じ
見つかった
リストも同じ
```

渡す値の型が `😛🐚要素の型🍆` を守っていないと、`🐦` はコンパイルエラーになります。

```emojicode error
🕊 🧺 🍇
  🖍🆕 apples 🔢
  🆕 🍼 apples 🔢 🍇🍉
🍉

🏁 🍇
  🍿 🆕🧺 0❗️ 🍆 ➡️ baskets
  ↪️ 🐦 baskets 🆕🧺 1❗️❓ 🍇
    😀 🔤見つかった🔤❗️
  🍉
🍉
```

```text
has no suitable 🐦
```
