# 値型と列挙型

## 値型（🕊）

`🕊` で作る型は **値型** です。クラス（`🐇`）との違いは、代入したり引数に渡したりすると **コピーされる** ことです。座標や色のような、小さなデータのまとまりに向いています。

```emojicode
🕊 📍 🍇
  🖍🆕 x 🔢
  🖍🆕 y 🔢

  🆕 🍼 x 🔢 🍼 y 🔢 🍇🍉

  ❗️ 🔡 ➡️ 🔡 🍇
    ↩️ 🔤(🧲🔡 x❗️🧲, 🧲🔡 y❗️🧲)🔤
  🍉

  🖍❗️ 🚶 dx 🔢 dy 🔢 🍇
    x ⬅️➕ dx
    y ⬅️➕ dy
  🍉
🍉

🏁 🍇
  🆕📍 1 2❗️ ➡️ 🖍🆕 a
  a ➡️ 🖍🆕 b
  🚶 b 10 0❗️
  😀 🔡 a❗️❗️
  😀 🔡 b❗️❗️
🍉
```

```output
(1, 2)
(11, 2)
```

`a` を `b` にコピーしてから `b` だけを動かしたので、`a` は変わっていません。

インスタンス変数を書き換えるメソッドには、`🖍❗️` のように `🖍` をつけます。このメソッドは、`🖍🆕` で作った（書き換えられる）変数に対してしか呼べません。

```keywords
struct
構造体
値型
value type
コピー
値渡し
mutating
```

## 列挙型（🔘）

`🔘` で、決まったいくつかの値のうちどれか 1 つ、を表す型を作ります。値は `🆕▶️名前` で並べます。

```emojicode
🔘 🚦 🍇
  🆕▶️🔴
  🆕▶️🍋
  🆕▶️🍏

  ❗️ 🔡 ➡️ 🔡 🍇
    ↪️ 👇 🙌 🆕🚦▶️🔴❗️ 🍇
      ↩️ 🔤止まれ🔤
    🍉
    🙅↪️ 👇 🙌 🆕🚦▶️🍏❗️ 🍇
      ↩️ 🔤進め🔤
    🍉
    ↩️ 🔤注意🔤
  🍉
🍉

🏁 🍇
  🆕🚦▶️🔴❗️ ➡️ light
  😀 🔡 light❗️❗️
  😀 🔡 🆕🚦▶️🍏❗️❗️❗️
🍉
```

```output
止まれ
進め
```

値は `🆕型▶️名前❗️` で取り出し、`🙌` で比べます。列挙型にもメソッドを書けます。

```keywords
enum
enum class
列挙型
列挙
定数の集まり
```
